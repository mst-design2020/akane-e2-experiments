# E11-1 計画：物の語そのものの「普通の意味」をGemmaに選ばせる（2026-11-12、本人「それで行こう」）

前の E11 案（PLAN_E11.md、11-11 保留）を、本人の言う「E8 の裏付けを主にした小さな実験」に絞った版。
先行：plans/E8_prior_work.md、plans/E11_box_dictionary_prior_work.md、この計画の末尾。

## なぜ
- E8 で「途中の語の意味を Gemma に選ばせる」と取り違えが大きく減り、一覧なしの確かめ直し（E8n）でも残った。
- 11-12 に E8n（方法D）の間違った「はい」65問を数えると、40問は途中ではなく 1 段目（物の語そのものの説明文）だった（plans/E11_count_E8_errors.md）。私が読んで分けた大まかな中身は、珍しい意味 約15、分類の境目 約15、NLIの間違い 約10。E8 は物の語そのものの意味は選ばず、全部の意味から道を探している。
- なので、同じ「意味を選ばせる」を 1 段目にも広げる。この数えは小さく、きっかけとして使うだけ（主張の根拠にはしない）。

## 2本立て
### ① 文なしの「普通の意味」選びを、公開データで大量に測る
- データ：WordNet 3.0 の名詞と、意味ごとの SemCor の回数（nltk の lemma.count()。人が意味を付けた文の集まりで数えた回数）。
- 問題の選び方（決まり）：意味が2〜8個の名詞（E8 と同じく候補は8つまで、番号が1桁で済む）で、一番多い意味の回数が3以上、かつ2番目より多い物。そこから種0で2,000語をくじで選ぶ。
- 正解：回数が一番多い意味。
- 注意：WordNet の意味の順番は SemCor の回数順なので、「最初の意味」はほぼ正解そのもの。比べ相手にならないので、候補はくじで並べ替えて見せる。
- 方法：
  - S0 でたらめ（1/意味の数）
  - S1 語と説明文の近さ（文のベクトル all-mpnet-base-v2 で、語そのものと各説明文の近さが一番大きい物。Bhingardive 2015 の考えに近い、AIなし）
  - S2 Gemma（「この語の、日常の英語で一番よく使う意味はどれ？」、番号の値が一番大きい物）。並べ順の癖を消すため、くじの順とその逆順の2通りの平均。
- 主な比べ：S2 対 S1、S2 対 S0。差あり＝語で1,000回取り直して差が5ポイント以上、かつ95%の幅が0をまたがない。
- 分けて見る：意味の数（2〜3／4以上）、一番多い意味の割合（回数の偏りが大きい語・小さい語）。

### ② それで E8 の 1 段目を直す
- 材料：E8n の結果そのまま（ドライブ E8n_results.json、方法D＝途中の意味は Gemma）。物の語の意味の一覧も E8n の Wiktionary の読み取りそのまま。NLI・鎖・問題（700＋300）・正解は変えない。新しく取るのは、物の語の意味を Gemma が選んだ値だけ。
- 方法（1段目の意味の扱い。どれも、そこから先の鎖は E8n の方法D）：
  - R0 全部の意味から道を探す（E8n のまま）
  - R1 Wiktionary の最初の意味だけ（AIなし、強い比べ相手）
  - R2 Gemma が選んだ普通の意味だけ（S2 と同じ聞き方、2通りの平均で一番大きい物）
  - R3 Gemma の値で重みを付ける：点数 ＝ Σ_k p_k × f_k（f_k は意味 k から出た一番強い道の掛け算、p_k は Gemma の値）
  - 参考 R4（主張には使わない）：分類を見せて選ばせる（「"x is a type of C." の x はどの意味か」）。分類を見せると「はい」になる意味を選びやすくなるかを見るためだけ。
- 点数：一番強い道の掛け算（E8 の ⑥、学習なし）。「はい」＝点数 > 0.5。
- 主な比べ（700問、正解は Claude の常識判定）：
  - 比べ1 R3 対 R0（1段目に重みを付けると良くなるか）
  - 比べ2 R3 対 R1（Gemma は最初の意味より良いか）
  - 物差しは AURC（E6〜E10 と同じ）。差あり＝物の語で1,000回取り直して、差が相手の20%以上、かつ95%の幅が0をまたがない。
  - 副：R2 対 R1、R2 対 R0。Gemini の常識判定でも同じ比べ。間違った「はい」の数と、正しい「はい」を壊した数。
- 確かめ（新しい300問、1回だけ）：700問で R1〜R3 のうち AURC が一番良かった物を、R0 と AI の自信（E8 と同じ値）と比べる。決まりは同じ。
- 副（学習あり）：E8n の木の学習（e8n_analyze_gb.py）の特徴に、選んだ方法の点数を足す・置き換える。5回・相手の20%以上で5回中4回（E8n と同じ決まり）。

## 言えたら「効いた」とする所（先に固定）
- ①：S2 が S1 と S0 の両方に差あり → 「小さいAIは、文がなくても語の普通の意味をかなり選べる」。
- ②：比べ1が差あり、かつ新しい300問でも R0 より良い → 「1段目の意味選びが効く」。比べ2が差なしなら「最初の意味で足りる（Gemma は要らない）」と書く。
- どちらも届かなければ、そのまま「効かなかった」と書く。

## 予想（流す前に書く）
- ①：S2 は 55〜65% ほど（McCarthy 2007 の、文なしで一番多い意味を探す方法が名詞で約55%）。S1 より上、差は5ポイント前後で五分五分。
- ②：Wiktionary は普通の意味を先に書くことが多いので、R1 だけで珍しい意味の間違いの多くは消えると見込む。ただ R1 は、最初でない意味を通る正しい答えを壊す。R3 は壊しが少なく、R0 より良い見込み（比べ1は差ありが6割）。比べ2（R3 対 R1）は差なしの見込みが高い。
- 分類の境目の間違い（バーベルは道具か）と NLI の間違いは、どれでも直らない。

## 正直な位置づけ
- よく使われる意味を見つける研究は昔からある（McCarthy ほか 2004・2007、Bhingardive ほか 2015）。新しい方法とは言わない。「辞書で確かめる流れの中で、どこを直すと効くか」の確かめ。
- 常識の判定は、もともと語の普通の意味で付けている。なので「普通の意味を選ぶ」は、判定の付け方と筋が合っている。そのことを結果にも書く。
- ①は WordNet の意味、②は Wiktionary の意味。①で測れるのは「Gemma の普通の意味を選ぶ力」で、Wiktionary の上での力そのものではない。
- 700問は E6 からずっと使っている。決めるのは700問、確かめは300問で1回だけ。

## 先行（この計画のために足した物）
- McCarthy ほか 2007（CL 33(4)）：WordNet の意味は SemCor の回数順。文なしで一番多い意味を探す方法は名詞で約55%（でたらめ約32%）。最初の意味は WSD でとても強い（Senseval-3 で61.5%）。
- Bhingardive ほか 2015（NAACL）：語のベクトルと意味の説明文の近さで一番多い意味を探す。SemCor の最初の意味には全体で負ける。
- Meconi ほか 2025（arXiv 2509.13905）：文の中の意味選びで gemma-2-2b-it 72.4%（最初の意味 65.2%）。小さいモデルは前に並んだ候補に引っぱられる。文なしは測っていない。
- Kovács ほか 2022：Wiktionary の「まれ・古い」の印のない最初の意味で98%以上当たる（印の一覧を使うので、ここでは使わない）。

## 結果（2026-11-12 16:40 JST、results/E11-1_analysis.json、分析 e111_analyze.py）
旗：① True、② False、「最初の意味で足りる」True。
### ①（WordNet 2,000語、正解は SemCor の一番多い意味）
- 当たり：でたらめ 33.2%、語と説明文の近さ 47.1%、Gemma 59.2%。Gemma−近さ +11.9（95%幅 9.2〜14.4）、Gemma−でたらめ +25.9 → 決まりで「差あり」。予想（55〜65%）どおり。
- 意味2〜3：68.6%（近さ56.7）、4以上：46.8%（34.7）。偏りの大きい語 70.4%、小さい語 47.9%。
- 注意：WordNet の最初の意味は SemCor の回数で並んでいるので、ここでは100%当たる。回数の並びがある辞書なら Gemma は要らない。Gemma が役に立つのは回数の並びがない時（Wiktionary など）だけ。
### ②（E8n 方法D の1段目）
- 700問 AURC 常識：R0 0.063、R1 0.063、R2 0.061、R3 0.056（R3−R0 差 0.008、95%幅 0.001〜0.016、相手の12%で基準20%に届かず＝同着）。Gemini 判定：R0 0.074、R3 0.076（同着）。間違った「はい」54→24（R3）、ただ正しい答えへの「いいえ」52→72。
- 新しい300問（700問で R3 を選んだ）：R0 0.056、R3 0.074（R3 が悪い：差 −0.018、95%幅 −0.036〜−0.004）、自信 0.118。300問では R0 の間違った「はい」がもともと11しかなく、直せたのは6、正しい「はい」を12壊した。
- 木の学習：R0 平均0.053、R3 0.045。5回中5回 R3 が良いが、20%以上は1回だけ（基準4回）＝同着。
- Gemma が Wiktionary の最初の意味を選んだ割合 67%。300問で壊した例：goldfish（「忘れっぽい人」を選んだ）、gander（「ちらっと見ること」）、bobby（警官。問いは動物の意味）、reeve（役人。問いは鳥）。問いが普通でない意味を聞いている物と、Gemma の選び間違いが混ざる。
### 見立て
- ①は「小さいAIは文なしでも普通の意味をそこそこ選べる（6割）」。ただ回数順の辞書には遠く及ばない。
- ②は効かなかった。1段目の取り違えは確かにあるが（700問で間違った「はい」が半分以下に）、意味を絞ると正しい答えも同じくらい壊れる。問いの中には普通でない意味を聞く物があり、「普通の意味」に絞ること自体が合わない場面がある。
