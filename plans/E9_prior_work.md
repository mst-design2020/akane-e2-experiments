# 網（確率伝搬（BP））の出番は本当にないか ― これまでの整理と先行研究（2026-11-10）

## 1. これまでの結果（E2〜E8）で網はどうだったか

| 実験 | 網の相手 | 結果 |
|---|---|---|
| E2-0 作り物の網 | 矛盾の数を数える | 網（BP・p-bit方式）が上 |
| E2-10 BTProp（公開の木） | BTProp | WikiBioはBTProp上、FactCheckGPTは同着 |
| E2-11 つながりをわざと2〜5割反転 | BTProp | ルールも疑うBPが上（わざと反転した時だけ） |
| E2-12 本物の外れ（NLI・Gemma） | BTProp | 疑うBPは同着か負け |
| E3 資料で「分からない」 | AIの自信／特徴＋学習 | 自信と同着、特徴＋学習に5/5負け |
| E4-1・E4-2 大きな網（8万問） | 特徴＋学習 | 大きな網は「はい」に倒れる。慎重な網≒学習（0.079対0.086、同着） |
| E4-3 正解なし | 自信／数える | 自信には勝ち、数えると同着 |
| E5・E5-2 AIが作ったルール | 全部信じる網／数える | ルールも疑う網＝全部信じる網 |
| E7・E8 辞書の鎖 | 一番強い道の掛け算 | 同着か負け |

まとめると、網は「AIの自信だけ」にはよく勝つが、「矛盾を数える」「掛け算」「特徴＋学習」のような単純で強いやり方には一度も差をつけていない。勝ったのは作り物の網と、つながりをわざと反転させた時だけ。

共通点：どの実験でも、網に入れる手がかりは**全部の主張に同じだけある**（どの主張にもGemmaの自信がある）。網の仕事は「つじつまを合わせて少し直す」だけで、その分は数える・学習でもほぼ取れてしまう。

## 2. 網が単純なやり方に勝つ条件 ― 先行研究から

### 2-1. 古典：まとめて分類（collective classification）
- **Sen ほか, AI Magazine 2008「Collective Classification in Network Data」**（https://linqs.org/assets/resources/sen-aim08.pdf）
  - 作り物のデータで、つながった相手どうしが同じ答えになりやすい度合い（同類性）が低いと、網あり・網なしは「同じくらい」。同類性0.9では差が約40点。
  - 本物（論文の引用網 Cora）では網ありが約8〜11点上、CiteSeerでは1〜4点。
  - 輪のBPは、短い輪が多く網が密になると急に悪くなる（E4の「倒れる」と同じ形）。
  - 読み取り：網が効くのは「1つずつの手がかりが弱く、となりどうしが強く結びつく時」。E2〜E8は逆で、Gemmaの自信など1つずつの手がかりが十分強かった。

- **Bilgic・Getoor, KDD 2008「Effective label acquisition for collective classification」**（https://linqs.org/assets/resources/bilgic-kdd08.pdf）／**AAAI 2010「Active inference for collective classification」**（https://linqs.org/assets/resources/bilgic-aaai10.pdf）
  - 使うときに「いくつかだけ本当の答えを確かめてよい（回数に上限）」とする。どれを確かめるかを網で選び、確かめた答えを網でとなりに広げる。
  - 選び方「間違っていそうな島の真ん中を確かめる（Reflect and Correct）」が、でたらめに選ぶ・つながりの多い所から選ぶ等より上（Coraで次点より最大18点）。
  - 読み取り：網の本当の出番は「**確かめる手間に限りがある時、少し確かめた結果を残りに広げる**」こと。1つずつのやり方（自信・特徴＋学習）は、確かめた主張しか直せない。

### 2-2. 知識の網（NELL など）
- **Pujara ほか, ISWC 2013**（知識グラフをPSLでルールと同時推論）・**Jiang・Lowd・Dou, ICDM 2012**：AIの自信 0.765 → 網 0.79〜0.90。ただしE4-2で再現せず（E4の資料）。
- **Platanios ほか, NeurIPS 2017**：正解なしで分類ルールから誤り率を推す。E4-3で試し、数えると同着。

### 2-3. LLMの答えのつじつま
- **BeliefBank（Kassner ほか, EMNLP 2021, arXiv 2109.14723）**：答えをためて、ルールで矛盾を直し、直した答えを次の質問の手がかりとして戻す。つじつまと正しさが上がる。ただし比べる相手は「自信だけ」で、数える・学習とは比べていない。
- **ConCoRD・REFLEX・BTProp・QXR**：E2の調査で確認済み。どれも「全部の主張に手がかりがある」形で、確かめる回数の限りは扱っていない。

### 2-4. 探したが見つからなかったもの
- 「LLMの答えのうち一部だけを外の確かめ役（辞書・資料・人）で確かめ、その結果を答えどうしのつながりで残りに広げる」研究は、今回の検索（英語、2024〜2026中心）では見当たらなかった。
  - 近いが別：確かめる主張を減らして費用を下げる研究（Valentin ほか 2024 arXiv 2407.21424「Cost-Effective Hallucination Detection」は1つずつの判定で、答えどうしに広げない）。
  - 見落としの可能性はある。計画が決まったらもう一度しぼって探す。

## 3. 空いている所（案）

**「確かめる手間に限りがある時、網は少ない確かめで多くを直せるか」**
- 古典（Bilgic・Getoor）は論文の引用網で、確かめ役は正しい答え（人）。
- AKANEの形では：答えるのは小さいAI（Gemma 2B）、つながりは分類のルール、確かめ役は辞書（E6〜E8の仕組み、間違うこともある）。
- 比べる相手に「特徴＋学習（となりの確かめ結果も特徴に入れる版）」を必ず入れる。これに勝てなければ、網の出番はやはりないと言える。

ほかの候補（優先度は下）：
- **学習用の正解がない新しい分野**：特徴＋学習はWordNetで学んだものを病気（DOID）に持っていくと崩れるかもしれない。網は正解なしで動く。E4-3（数えると同着）があるので期待は小さい。
- **1つずつの手がかりがわざと弱い場面**（自信が使えないAIなど）：Sen 2008の条件そのもの。ただ「わざと弱くする」のは作り物に近い。

## 4. 追加調査（2026-11-10 夜、雅也さん「もう少し調べて」）

### 4-1. 「単純な広げ方」が強いという古典
- **Macskassy・Provost, JMLR 2007「Classification in Networked Data」**（https://jmlr.org/papers/volume8/macskassy07a/macskassy07a.pdf）
  - 要旨（原文）：「とても単純な網の分類が、かなりよく働く」。
  - となりの答えの多数決（wvRN）に、何度か繰り返して落ち着かせる手（relaxation labeling）を組み合わせたものが、全体で一番強い組の1つ。正解が分かっている点が1割しかない時に、学習するやり方より上。正解が9割分かっている時は学習するやり方がやや上（0.61対0.57）。
  - 数字は論文の後半を要約で読んだもので、未確認。
  - 意味：E9では「ルールを1歩当てる」だけでなく「となりの多数決を繰り返す」も相手に入れるべき。網（BP）がこれに勝てないなら、網を使う理由はない。
- **Gallagher・Tong・Eliassi-Rad・Faloutsos, KDD 2008「ghost edges」**
  - 原文：「確かめ済みのとなりが少なすぎると、網の分類は失敗しうる」。「学習するやり方は、確かめ済みの割合が小さいほど、学習しないやり方より大きく傷む」。
  - 2歩以上先まで見る工夫で AUC が最大15点上。となりどうしが逆の答えになりやすい網では、単純な多数決は情報が増えるほど悪くなった。
  - 意味：網が単純なやり方を上回る見込みがあるのは、「確かめ済みが遠くにしかない（2歩以上）」か「打ち消し（両立しない）のつながりが多い」時。
- **Huang ほか, ICLR 2021「Correct and Smooth」**（arXiv 2010.13993）
  - 網を見ない単純な学習のあとに、網で「間違いを広げて直す」「答えをならす」を足すだけで、複雑な網の学習（GNN）を上回った（原文：パラメータ137分の1で最高記録を超えた）。
  - 意味：網は「学習の代わり」ではなく「学習のあとの仕上げ」として効く、という前例。これまでのAKANEの実験では、網に入れるのはGemmaの自信で、**特徴＋学習の答えを網に入れて仕上げる形は試していない**。

### 4-2. 1つ直したら、つながった答えも直るか（AIの知識の書き換え）
- **RippleEdits（Cohen ほか, TACL 2024, arXiv 2307.12976）**：AIの中の事実を1つ書き換えると、つながった事実（例：親を変えたら兄弟も変わる）も変わるべき。調べると、AIの重みを書き換えるやり方はほとんど広がらない。一番良かったのは、書き換えた事実を質問の前に書き足すだけの単純なやり方。
- **Hase ほか, EACL 2023**：AIの信念を1つ書き換え、つながった信念がついて変わるかを網で見る。LeapOfThoughtで「つながった先もついて変わる」のは24%ほど。
- **Deductive Closure Training（Akyürek ほか, 2024, arXiv 2401.08574）**：元の事実からAIに「そこから言えること」を作らせ、つじつまの合うものを選んで学習し直す。正しさ3〜26%上。広げ方はAIの学習し直しで、外の網ではない。単純なルール1歩とは比べていない。
- **REFLEX（Kassner ほか, 2023）**：人が直す実験はなく、「先の課題」とだけ書いてある。
- 意味：「1つ直したらつながった答えも直す」はAIの中を書き換える形では難しい、と分かっている。**AIの外の網で広げる形**を、確かめ役・確かめる数の上限つきで測った研究は、今回も見つからなかった。

### 4-3. 確かめる数に上限がある研究（AIの時代）
- **KAEL（Dong ほか, WSDM 2023）**：知識グラフの誤り探しで、人に聞ける数に上限を置き、どれを聞くかを選ぶ。聞いた結果をつながりで広げることはしていない。
- **CoAnnotating（EMNLP 2023）・MEGAnno+（EACL 2024）**：AIの付けた答えのうち、あいまいなものだけ人に回す。1つずつで、広げない（E9の「あいまいなものを確かめる・確かめた所だけ直す」がこれに当たる）。
- **GraphEval（Feng ほか, ICLR 2025）**：AIがアイデアを要素に分け、似ているものを網にして、正解の分かったものからラベルを広げる。学習なしで広げるだけ（70%）が、AIに直接聞く・BERTを学習（66%）より上。網は「似ている」つながりで、論理のルールではない。
- **Probabilistic Label Spreading（Klees ほか, arXiv 2602.04574, 2026）**：1つずつの人の答えを似ている者どうしに広げ、人の手間を大きく減らす（要旨のみ確認）。

## 5. 追加調査のあとの空いている所（直し）
次の4つが全部そろった研究は見つからなかった。
1. 答えるのは小さいAI
2. つながりは論理のルール（「一種」「両立しない」）
3. 確かめるのは外の確かめ役（辞書など、間違うこともある）で、数に上限
4. 網（BP）を、単純な広げ方（ルール1歩・となりの多数決の繰り返し）と、学習のあとの仕上げ（Correct and Smooth型）と、まとめて比べる

古典からの見込み：網が単純な広げ方を上回るのは「確かめ済みが遠い」「打ち消しのつながりが多い」時。学習の代わりではなく、学習のあとの仕上げとして効く可能性がある。

## 6. E9-3の前に（2026-11-11）：問題の作り方の癖と、強い相手との比べ方

E9-2と点検で、「比べ相手の学習が弱い」「問題の作り方の癖を学習が覚える」の2つが見つかった。同じ落とし穴の先行例。

- **問題の作り方の癖を覚える（近道学習）**
  - Gururangan ほか NAACL 2018「Annotation Artifacts in Natural Language Inference Data」：NLIの仮説文だけで正解の約67%が当たる。データの作り方の癖を、モデルが中身の代わりに覚える。 https://arxiv.org/abs/1803.02324
  - Geirhos ほか Nature Machine Intelligence 2020「Shortcut Learning in Deep Neural Networks」：近道学習の総まとめ。分布の違う問題で確かめることを勧める。 https://arxiv.org/abs/2004.07780
  - Akrami ほか SIGMOD 2020「Realistic Re-evaluation of Knowledge Graph Completion Methods」：知識グラフ補完の評価データの作り方の癖（逆向きの関係がそのまま残る）で、方法の強さが大きく見えていた。癖を除くと順位が変わる。 https://arxiv.org/abs/2003.08001
  - E4-2の候補（本当の分類はつながる、Gは一番信じたうそ）は、まさにこの形。**E9-3は候補を選ばず、46分類すべてを聞いた答えを使う**ことで癖を除く。
- **強い単純な相手と比べる**
  - Kadlec ほか 2017「Knowledge Base Completion: Baselines Strike Back」：調整した古い単純な方法が、新しい方法の多くに勝つ。 https://arxiv.org/abs/1705.10744
  - Ruffinelli ほか ICLR 2020「You CAN Teach an Old Dog New Tricks!」：学習のさせ方をそろえると、新旧の差の多くが消える。
  - Shchur ほか 2018「Pitfalls of Graph Neural Network Evaluation」：分け方・調整をそろえると、グラフの方法の順位が入れ替わる。 https://arxiv.org/abs/1811.05868
  - Huang ほか ICLR 2021「Correct and Smooth」：つながりを使う大きな方法に、単純な学習＋つながりでの仕上げが並ぶか勝つ（E9のFの元）。 https://arxiv.org/abs/2010.13993
  - Grinsztajn ほか NeurIPS 2022「Why do tree-based models still outperform deep learning on tabular data?」：表の形の特徴では、木の学習（勾配ブースティング）が強い相手。 https://arxiv.org/abs/2207.08815
  - →**E9-3は、直線の学習と木の学習の両方を相手にし、強い方と比べる**。
- **空いている所（変わらず）**：小さいAIの答え×AI自身が作ったルール×外の確かめ役（辞書）で数に上限、のときに、網で広げるのが強い学習に勝つか。癖を除いた問題で確かめた例は見つからない（見落としの可能性あり）。
