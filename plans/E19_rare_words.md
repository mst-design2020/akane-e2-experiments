# E19 計画：AI が知らない珍しい言葉なら、辞書をたどると効くか

2026-11-14 10:27 本人「わかった。やろう」。先行：E19_先行研究.md。結果を見る前にここで固定する。

## 問い
Gemma-2 2B が知らない珍しい言葉で、「X は Y の一種か」に TADORI（辞書の鎖）を足すと良くなるか。
説明文を 1 段見せるだけより良いか。9B に届くか。よく出る言葉では効かない（E17・E18）ことも同時に確かめる。

## データ
- X：WordNet の名詞の見出し語（小文字の a〜z だけ、3文字以上）。46 分類のどれかの下に入る意味を持つ語。分類の語そのものは除く。
  - さらに Wiktionary（E10-1 と同じ読み方）に英語の名詞の見出しがある語だけ。辞書が無い語では TADORI も説明文も使えないので、そこは比べない（届く割合だけ出す）。
- 珍しさ：wordfreq の zipf 値（英語）。**よく出る ≥ 3.0、中くらい 1.5〜3.0、珍しい < 1.5**（0＝wordfreq に無い、も珍しいに入る）。各段から **200 語**を乱数（種 0）で選ぶ。
- Y：E4-2・E10-3 K と同じ 46 分類（問いの定義、分類の名前も同じ）。600 語 × 46 ＝ 27,600 組。
- 正解（主の採点）：X のどれかの名詞の意味から、WordNet の上位語（instance も）をたどって Y の分類に着けば「一種」。
- 手書きの語の一覧なし。手で決めた数：段の境目 1.5・3.0、各段 200 語、種 0、説明文は 3 つまで、余裕 0.03。

## 方法（しきい値は「よく出る」段の 200 語で、釣り合った正しさが一番の所に決める。試すのは全部の段）
- G2：2B に説明文なしで聞く（E17 と同じ）Yes−No の値 > θ。
- G9：9B に同じ問い > θ（大きい AI）。
- S（説明文を見せるだけ）：X の辞書の説明文（最初の 3 つまで）を見せて 2B に聞く（E15 と同じ聞き方）> θ。
- T：TADORI の点 ≥ τ（作り方は E17 と同じ。3段、親の語は NLI、途中の語の意味は 2B、最後の段は NLI）。
- **TO（主）：G2 > θ または T ≥ τ**（2B が知らずに「いいえ」と言う所を、辞書の道が見つかれば「はい」にする）。θ と τ は一緒に決める。

## 物差し
- 主：釣り合った正しさ BA ＝ ½×（一種の組で「はい」の割合）＋ ½×（一種でない組で「いいえ」の割合）。段ごと。
- 副：段ごとの「はい」の割合・「いいえ」の割合、9B との差。
- 95% の幅：X の語ごとに引き直す、2,000 回。

## 決まり（先に固定、主は「珍しい」段）
- 旗A（主）：BA(TO) − BA(G2) ≥ 0.03 かつ幅が 0 より上 →「珍しい語で TADORI が効く」。差 < 0 で幅が 0 より下 →「悪くなる」。それ以外は同着。
- 旗B：BA(TO) − BA(S) に同じ決まり（たどる仕組みが、説明文を見せるだけより良いか）。
- 旗C：BA(TO) − BA(G9)：≥ −0.03 かつ幅の上が 0 より上 →「9B に届く」、差 ≥ 0.03 で幅が 0 より上 →「9B より上」、それ以外は「届かない」。
- 確かめ：「よく出る」段では旗A が同着か悪くなる、と予想（E17・E18 と同じ）。外れたら書く。

## 常識での確かめ（[[feedback-claim-after-common-sense]]）
- WordNet の正解表だけでは「効く」と言わない。
- 「珍しい」段で、比べる 2 つの方法の答えが違う組（TO と G2、TO と S、TO と G9）だけを、方法を伏せて Claude が常識で「一種か」を判定する（各比べ最大 1,000 組、多ければ種 0 で選ぶ）。判定した組は正解を常識に置き換えて、旗をもう一度出す。
- 旗が WordNet と常識の両方で同じ向きの時だけ、その結論を書く。2 つの AI に判定させた（人ではない）と書く。

## 結果（主＝珍しい段、釣り合った正しさ）

## 注意（書く時に必ず添える）

## 言えること（今の所）
珍しい言葉では、2B に辞書の説明文を見せると「一種か」が大きく良くなり、9B より上になった（WordNet・常識の両方）。ただし効いているのは主に「説明文を見せること」で、TADORI のたどる仕組みの上乗せは小さい（同着）。
