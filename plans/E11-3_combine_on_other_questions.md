## 問い
E11-2 の「全部入りの木の学習」は、問いや問題を替えても、Gemma の値だけの木の学習（C++）より良いか。

## 場面（どれも、もう取ってある材料だけで行う。Colab は使わない見込み）
- **K 一種か（別の問題）**：E10-3 の K（E4-2 の 501語×46分類＝23,046主張、常識600は E9-3 の Claude 判定）。E8 とは問題が違う。主。
- **P 部分と全体**：E10-1 の問題 N（325語×30＝9,750主張、常識600×Claude、Gemini も）。主。
- **D 病気・G 地理**：E10-1 の問題 N。副（一般的な文がほぼ見つからない場面）。

## 入れる手がかり（場面ごとに、取ってある物を全部。新しく取らない）
- 共通：Gemma の自信と、その語の他の分類への答えの並び（E10 の C++ の特徴 FG）。
- K：E9n の辞書の鎖の確かめ（E8 の流れ、一覧なし）、⑩ 辞書の説明文を見せた値、⑪g 一般的な文を見せた値、⑫ 自分で書いた文を見せた値、NLI。
- P・D・G：E10-1 の辞書1段・一覧なしの鎖（⑥N）・直し1〜4と向き、E10-2 の ⑩・⑪g・NLI（P は E10-3 の ⑫ も）。
- 箱：E10-1・E9n の段と着きの組から、E11-2 と同じ作り方で学習できる場面だけ入れる（学習できない場面は理由を書いて外す）。手で決めた数は E11-2 と同じ。

## 比べ（先に固定）
- 学習：E10 と同じ（WordNet の正解で学習する分け方、木の学習 HistGB、5回）。採点：常識の判定（Claude が主、Gemini も並べる）。
- 主な比べ：**全部入り 対 C++**（各場面）。副：全部入り 対 その場面で今までに一番良かった学習（K・P は X++、D・G は ⑧N++）。
- 差あり＝5回中4回、相手の20%以上良い（E10 と同じ）。
- 「繰り返せた」とする所：**主の2場面（K・P）の両方で**、全部入りが C++ に差あり。1つだけなら「場面による」と書く。D・G は副として並べる。
- 事後の見方（主張には使わない）：手がかりを1つずつ抜いて、何が効いているかを見る。

## 予想（流す前に書く）
- P：全部入りは C++ に勝つ（E10-2 の X++ がもう勝っているので、見込み8割）。ただし X++ との差は小さい（同着の見込み）。
- K：E10-3 では資料を見せる手がかりはどれも ① と同着だった。E9n の辞書の鎖は「学習に足す材料として効く」だったので、全部入りは C++ に勝つ見込み5割。
- D・G：一般的な文がないので、⑧N++ と同じく C++ と同着の見込み。

## 正直な位置づけ
- 手がかりを学習でまとめるのは、よく知られたやり方。新しい方法とは言わない。「辞書・資料・意味選びの手がかりが、問いを替えても足し算として効くか」の確かめ。
- 学習には正解付きの問題が要る（ここでは WordNet の正解）。
- 材料はどれも前の実験で取った物で、どの手がかりが効くかは一部もう見えている（E10-2 の X++ など）。なので、新しく分かるのは主に K と、箱・鎖を足した時の上乗せ。
