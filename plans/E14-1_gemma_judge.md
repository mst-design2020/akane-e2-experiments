# E14-1 計画：継ぎ足しの判定を NLI から Gemma に替える（2026-11-13 朝、本人「じゃあそのAIやめたら？Gemmaだけ聞いたら？」「やって」）

E14 の結果：E14_fill_gaps.md 末尾。継ぎ足しで正しい「いいえ」52中41が「はい」に変わったが、間違った「はい」が127増えて悪化。崩れの大きな原因は、NLI が「AはBの一種」と言っていない文（Granddaughters trump … win）にも高い値を付けたこと。

## 変える所（これだけ）
- 継ぎ足しの文に関わる判定を、NLI から Gemma に替える：
  - 文 → 親（どの候補を親にするか、その段の強さ）
  - 文そのものの分類への着き
- 聞き方（1つだけ、ほかは試さない）：
  `Sentence: {文}\n\nDoes this sentence say that a "{w}" is a kind of "{c}"? Answer Yes or No only.`
  値は Yes と No の差を確からしさに直した物（1/(1+e^−差)）。
- 辞書の説明文の段（E8n・E11-2 と同じ部分）は NLI のまま。E6 で辞書の説明文の判定は NLI が一番良かったため。
- 文の集め方・数（一般的な文20文を読んで3文、自作文1文）、意味選び、段の上限6は E14 と同じ。自作文は E14 で書かせた物をそのまま使う（同じ文で判定だけ替える）。

## 決まり（先に固定、E14 と同じ物差し）
- AURC、差あり＝物の語で1,000回取り直して、差が相手の20%以上かつ95%幅が0をまたがない。
- 主：⑭'gs 対 ⑥N（700、常識 Claude）。確かめ：同じ比べを300。
- 副：⑭'gs 対 ⑭gs（判定を替えて良くなったか）、⑭'s 対 ⑭s、⑭'g 対 ⑭s、Gemini 判定。
- 数え：正しい「いいえ」が「はい」に変わった数、間違った「はい」の増え。

## 正直に書いておくこと
- この1,000問は E14 で一度結果を見た問題。ここで良くなっても「後から合わせた」の疑いが残る。なので、700と300の両方で ⑥N に勝っても、言えるのは「候補が見つかった」まで。主張にするには、別の新しい問題（決まりで選んだ物）で確かめ直す。
- 事後に見えた「⑭s（自作文だけ）が300で良い」も、ここでは副の比べとして扱い、主にはしない。

## 予想（先に書く）
- Gemma は「Granddaughters trump … win」型の文に低い値を付け、間違った「はい」はかなり減る。⑭'gs は ⑭gs より差ありで良くなる。
- ただ、Gemma 自身の「はい」寄りの癖（E4〜E9 で見た物）があるので、⑥N に勝つかは五分五分より下。
- ⑭'s と ⑭s は近い（自作文はもともと「AはBの一種」の形の文が多い）。

- 主：⑭'gs 対 ⑥N は 700 で差ありで悪い、300 同着 → 旗「候補が見つかった」False。
- 副：Gemma に替えると少し良くなる向き（⑭'gs 0.140→0.124、⑭'g 0.103→0.090）が、どれも基準に届かず同着。⑭'s と ⑭s も同着。
- Gemma は「Granddaughters trump … win」に 0.04 を付けるなど、明らかな雑音文は落とせた。それでも間違った「はい」は減らなかった（181→184）。残った崩れ：「Progeny is a monthly column focusing on queer families」→ family 0.97、「Isolationist is only the latest example」→ example 0.99 のように、文の形が「X is a Y」の雑音文は Gemma も「一種」と読む。さらに継ぎ足しが何段も続くと、正しい段の積み重ねでも意味がずれていく。
- 予想と照らす：「Gemma は雑音文を落とし、⑭gs より差ありで良くなる」は外れ（向きは合うが小さい）。「⑥N に勝つのは五分五分より下」は当たり。

### まとめ（E14 と E14-1）
- 段不足は資料で埋まるが、埋めた分以上に間違った「はい」が増える。判定役を NLI から Gemma に替えても大きくは変わらない。原因は判定役より、一般的な文そのものの雑音と、継ぎ足しが何段も続くことによるずれ。
- 外の資料（一般的な文）より Gemma の自作文の方が良い傾向は E10-3・E14・E14-1 で一貫しているが、自作文だけでも今の鎖と同着（700）。
- 辞書の鎖を伸ばす・継ぎ足す方向は、ここで区切るのが良いと考えている。
