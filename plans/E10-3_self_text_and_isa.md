# E10-3 計画：自分で書かせた文との比べ・問いの種類×資料の表・意味のずれた文を除く（2026-11-12 朝、本人「やってみよう」）

候補の洗い出しと先行研究：E10-3_候補.md。E10-2 の結果：PLAN_E10-2.md 末尾。

## 一言で
E10-2 で「一般的な文（GenericsKB）を見せると、部分と全体の答えが良くなる」と分かった。書く前に3つ確かめる。
1. **外の資料が本当に要るか**：Gemma に自分で文を書かせて見せた時（⑫）と比べる（Abdallah 2025 で Gemma-2 2B は自分で書いた文の方が検索より良かった）。
2. **問いに合った資料か**：「一種か」の問題にも、辞書の説明文（⑩）と一般的な文（⑪g）と自分の文（⑫）を見せ、「一部か」と並べた表を作る。
3. **意味のずれた文を除くと良くなるか**（縁起の案）：見つけた文ごとに、Gemma に「問いと同じ意味で使われているか」を聞き、合う文だけを見せる（⑪f）。NLI も合う文だけで（⑪nf）。

## 問題（どれも正解と常識判定がすでにある。新しい判定はしない）
- **N の P**（E10-1 の部分と全体、9,750 主張）：1 と 3 の主な確かめ。一般的な文は E10-2 で見つけた物（E102_facts_N）をそのまま使う。
- **K**（一種か）：E4-2 の 77,326 主張のうち、E9-3 の常識600 に出る 501 語の全部の主張（501×46＝23,046）。語を決まりで選び（常識600 に出る語）、手で選ばない。① の値は E4-2 で取った物（聞き方は同じ）。一般的な文は E10-2 と同じ探し方で新しく探す。
- 常識の採点：N の P は Claude（主）・Gemini・両者一致、K は Claude（E9-3 の600、どちらとも＝2 は除く）。副に WordNet の正解。

## 聞き方（先に固定、ほかは試さない）
- ⑫ 書かせる：`Write up to five short, general, factual sentences that mention both "{x}" and "{W}". Write one sentence per line and nothing else.`（貪欲に、新しい語100まで）。行の頭の記号を外し、3語以上の行を最大5つ。それを E10-2 の ⑪g と同じ「Facts:」の形で見せて聞く。
- ⑪f の意味の確かめ：`Statement: {文}\nSentence: {一般的な文}\n\nIn the sentence, are "{x}" and "{W}" used with the same meanings as in the statement? Answer Yes or No only.` Yes−No の値が0より大きい文だけ残す（0は先に固定）。残らなければ「(no facts found)」。
- ⑩・⑪g・⑩s・⑪s は E10-2 と同じ（K は W＝分類名）。

## 決まり（E10・E10-2 と同じ）
- AURC、物を5つに分け2割で調整・8割で評価、5回。差が相手の20%以上かつ5回中4回以上で「差あり」。Gemma の値はどれも調整用の2割でロジスティック回帰をかけて確からしさに直す。
- **主な比べ1（N の P、常識 Claude）**：⑪g 対 ⑫。⑪g が差ありで良ければ「外の資料が要る」。同着なら「自分で書いた文でも同じくらい効く」と書き、E10-2 の言い方を弱める。⑫ が良ければ「外の資料より自分の文」と書く。参考：⑫ 対 ①、X++ に ⑫ を足した版 対 X++。
- **主な比べ2（K、常識 Claude）**：⑩・⑪g・⑫ それぞれ 対 ①、⑩ 対 ⑩s、⑪g 対 ⑪s。表にして、「一部か」（E10-2）と並べる。「問いに合った資料を選ぶと効く」と言うのは、K で ⑩ が ① と ⑩s の両方に差ありで良く、かつ E10-2 の P で ⑩ が効かなかった（済み）時。
- **主な比べ3（N の P）**：⑪f 対 ⑪g、⑪nf 対 ⑪n。
- 副：文が見つかった割合、意味の確かめで残った文の割合、珍しい語・身近な語（Zipf 3.5）で分けた値。

## 予想（先に書く）

## 結果（11-12 朝、e103_analyze.py、出力 e103/results/out_{claude,gemini,agree}.json）
数字は AURC（低いほど良い）、5回の平均。判定は先に決めた決まり（20%以上・5回中4回以上）。

### 比べ1：N の P（部分と全体、常識 Claude）
| 方法 | 値 |
|---|---|
| ① 何も見せない | 0.068 |
| ⑪g GenericsKB の文 | 0.039 |
| ⑫ 自分で書かせた文 | 0.044 |
| X++ / X++＋⑫ | 0.042 / 0.051 |
- ⑪g 対 ⑫：**同着**（0/5 対 0/5）。⑫ も ① に 5/5 で良い。→ **「外の資料が要る」は言えない**。E10-2 の言い方を「答えを書いた文を前に置くと良くなる。自分で書かせた文でもほぼ同じ」に弱める。予想1（⑫ は ⑪g に及ばない）は外れ、Abdallah 2025 と同じ向き。
- 両者一致の判定でも同じ（⑪g 0.044、⑫ 0.051、同着）。Gemini 判定ではどれも同着（E10-2 と同じ）。

### 比べ2：K（一種か、常識 Claude、23,046 主張）
| 方法 | 値 |
|---|---|
| ① | 0.095 |
| ⑩ 辞書（Wiktionary） / ⑩s 対照 | 0.099 / 0.092 |
| ⑪g GenericsKB / ⑪s 対照 | 0.106 / 0.142 |
| ⑫ 自分の文 | 0.075 |
| ⑪n NLI | 0.083 |
- ⑩・⑪g・⑫・⑪n どれも ① と**同着**。⑫ は21%良いが 2/5 回で基準に届かず。⑪g は対照⑪s より良い（5/5）が ① は超えない。参考で ⑫ は ⑪g に 5/5 で良い。
- 珍しい語だけでは ⑫ が ① に 5/5 で良い（0.070 対 0.094）。WordNet 採点でも ⑫ が ① に 5/5 で良い（0.011 対 0.016）、⑩ は ① より悪い（5/5）。
- → **「問いに合った資料を選ぶと効く」は言えない**（決まり：K で ⑩ が ① と ⑩s の両方に差あり → 満たさず）。予想2（K では辞書が効く）は外れ。E6〜E9 で辞書が効いたのは WordNet の説明文と鎖・意味選びを使った時で、ここは Wiktionary をそのまま見せる形だった（違いはこれ）。
- 文が見つかった割合：12%（正しい組で30%）。check_plain の差 最大0.062。

### 比べ3：意味の合う文だけ（N の P）
- ⑪f 0.045 対 ⑪g 0.039：**同着**（身近な語では ⑪g が 5/5 で良い）。⑪nf 0.089 対 ⑪n 0.097：同着。
- 意味の確かめで残ったのは見つかった文の24%、文が残った主張は7%。予想3の前半（同着）は当たり、後半（NLI が良くなる）は外れ。

### まとめ
- 5つの「言えるか」の旗は全部 False。
- E10 系で言えること：部分と全体では、答えを書いた文（外の文でも自分で書かせた文でも）を前に置いて聞くと Gemma の答えが良くなる。外の資料ならではの効き目、問いの種類に合わせた資料選び、意味のずれた文を除く工夫は、どれも示せなかった。
- 一種かでは、自分で書かせた文が一番良い数字（特に珍しい語・WordNet採点）だが、主の基準では同着。
