# E16-0 計画：Gemma は「逆向きの問い」に弱いか（11-13 本人「やってみて」）

目的：p-bitの網ならではの使い方「どこを固定しても残りが落ち着く＝どの向きにも答える」に出番があるかを、まず小さいAIの側から確かめる。先行研究は 先行研究_pbitの使い道.md 8節（Berglund 2023 逆向きの呪い、Camsari 2017、Fahlman・Hinton・Sejnowski 1983）。

## 問題
- 物と分類：E10-3 の K（501語×46分類、WordNetの正解）。物ごとに「一番細かい当てはまる分類」を正解にした組 514。
- 前向き：「{物} is a type of which of the following?」選択肢＝正解の分類＋外れ3つ。
- 逆向き：「Which of the following is a type of {分類}?」選択肢＝正解の物＋外れ3つ。
- 外れ：やさしい版＝当てはまらない物・分類をでたらめに。難しい版＝兄弟の分類（同じ親）とその物。兄弟の数は前向きと逆向きでそろえる。前向きの外れから正解の分類の子孫は外す。
- 正解の位置を A〜D に1回ずつ（8,224問）。Gemma-2 2B（これまでと同じ）、A〜Dの文字の確からしさで答え。
- 参考：自由回答（前向き「〜は何の一種？」、逆向き「〜の種類を20挙げて」）を WordNet で確かめる。

## 決まり（結果を見る前に固定）
- 差＝前向きの正しさ−逆向きの正しさ（組ごとに4つの位置の平均）。物ごとに引き直す2,000回で95%の幅。
- やさしい版・難しい版のどちらかで 差≥10ポイント かつ 幅の下>0 → 「逆向きに弱い」→ 次（E16-1：網を作る）へ。
- 両方で 差<5ポイント → 「逆向きに弱くない」→ この方向はやめる（1つ目の条件が立たない）。
- それ以外 → 相談。
- 見込み（先に書く）：「一種か」はネットの文に両方の向きで出てくるので、差は小さい見込み（Berglund の呪いは片方の向きでしか覚えていない事実で出る）。

## 手で決めた所（ハードコードの点検）
- 手書きの語の一覧はない。物・分類は E10-3 の K、外れは分類の木と正解の表から規則で選ぶ（乱数の種 0）。
- 手で決めたのは問いの文の形（2つ）・選択肢の数4・自由回答の数20・決まりの数値（10・5ポイント）だけ。
- 注意：WordNetの正解は狭いことがある（11-10 訂正）。外れの選択肢が常識では当たり（例：人に「哺乳類」）のことがある。前向きと逆向きに同じように効くので差の比べには大きく響かない見込み。
