## 先行

## 1. 組み合わせ方を学習で（主）
- LR：ロジスティック回帰（sklearn、特徴は S と log(T+1e-4)、標準化、class_weight=balanced、C=1）。しきい値の決め方と学ぶ所は E20 と同じ：W は「よく出る」段、E は tune 半分で学び、しきい値も同じ所で BA 最大に。
- 比べ：LR 対 SO（E20 の「または」）、LR 対 S。主な組（説明文に分類の語がない組）。
- 旗A（主）：W 全部で LR−SO が「効く」（差 ≥0.03 かつ下限 >0）の AI が 3つ中2つ以上。判定は多数決（3つのAI）を主、正解表と各AIは副。
- 旗B：E（SemEval test 半分）で同じ。
- 副：LRg（G・S・T の3つ）。W の「ふつう」「珍しい」段は学びに使っていないので、ここも見る。
- 手で決めた所：特徴の形（log）、C=1、学ぶ所（E20 と同じ）。語の一覧はなし。

## 2. 珍しい語で鎖が切れる理由を数える（副、数えるだけ）
- 主な組で正解（多数決）が「はい」の組を、段ごとに：鎖の点 T が SO のしきい値に届いた割合、T がほぼ 0（<0.01＝道が着いていない）の割合、届かないが 0.01 以上（着いたが最後の判定が弱い）の割合。
- 鎖の道そのもの（途中の語）は Colab にしか残っていないので、ここでは点だけで分ける。

## 結果（11-14 夕、results/E20-1_out.json）
1. 学習で合わせる（LR）：旗A・B とも 0/3、どの判定（多数決・正解表・Claude・ChatGPT・Gemini）でも SO と同着か少し悪い（差 −0.008〜+0.007）。G も足す LRg は SO より +0.00〜+0.01 で基準 0.03 に届かない。→「または」の決まりで十分、組み合わせ方の伸びしろはない。
2. 数える（主な組・多数決で「はい」、W）：鎖が届いた割合は どの段も 82〜88%、道が着かないのは 11〜13%（段で変わらない）。違うのは「説明文だけで当たる」割合：Qwen・Phi は よく出る 59% → 珍しい 85〜87%、Gemma 12% → 52%。→ 珍しい語で鎖が効かないのは鎖が切れるからではなく、珍しい語は説明文だけで足りるから（説明文が具体的）。両方とも外すのは 7〜14%。残る穴は「道が着かない」約1割で、これは E14 で資料を足して埋めようとして雑音で悪くなった所と同じ。
