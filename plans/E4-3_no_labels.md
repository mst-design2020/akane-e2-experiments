# E4-3 計画案：正解の付いたデータがない場面で、網は効くか

2026-11-09 固定（雅也さん「やってくれ」、結果を見る前）。先行調査 E4-3_先行研究.md。

## 問い
正解を一切使わない場面で、Gemmaの答えと分類のルールを網でまとめると、
1. AIの自信・矛盾を数えるより、「分からない」と控える力（AURC）が上がるか
2. 網の中で、Gemmaの「いいえ」寄りの癖を正解なしで推し量れるか（Platanios 2017・Dawid–Skene の考え方）
3. 使い回す分類の主張を動かさない「慎重な網」は、正解なしでも効くか

## データ（新しくGemmaに聞かない）
E4-2と同じ。名詞1,681×46分類のGemmaの答え（E42_gemma-2-2b-it.json）、候補（正しい≤4＋G・H・E）、ルール（主張11,864・ルール55,136）。正解は評価だけに使う。
評価はE4-2と同じ5つの分け方の「評価用8割」の名詞（E4-2の数字と並べられるように）。調整用2割は、どの方法でも使わない。

## 比べる方法（全部、正解なし）
① Gemmaの自信：σ(logit)
② 矛盾を数える：E4-1の②と同じ形、強さ W=1・λ=1 で固定（調整なし）
③ 正解なしの癖の推し量り（網なし）：Gemmaのlogitを10段に分け、「本当のとき／うそのときに各段が出る割合」を、期待値最大化（EM）で推し量る。本当の割合の事前値も同時に推し量る。主張どうしのつながりは使わない（＝ルールなしのDawid–Skene、1人の答え手）
④ 正解なしの大きな網：③と同じ「各段が出る割合」を、網の周辺確率（BP）を使ってEMで推し量る（Platanios 2017と同じ考え方を、1つのAI・AIの分類の知識で）。ルールの強さは W=2 に固定
⑤ 正解なしの慎重な網：④と同じだが、分類どうしの主張は Gemmaの値（③の推し量り）に固定し、物の主張からは動かさない
⑥ 正解なしの小さな網：④と同じ推し量りを、名詞ごとの小さな網（分類どうしの主張を名詞ごとに写す）で
⑦ 正解なしの癖消し（Batch Calibration, Zhou ほか 2024）：評価する主張の束でGemmaの「はい」の確率の平均をとり、logitからその分を引く（主張の種類ごとに別に）。網なし。
（参考、正解を使う）E4-2の③特徴＋学習 0.086、⑤'慎重な網 0.079。上限の目安として並べるだけで、勝ち負けの判定には入れない。

- EMの始め方：Gemmaの答えをそのまま信じる所から（「偶然よりは良い」の前提。Platanios 2017と同じ）。50回か、変化が1e-4未満で止める。
- ルールの強さ W は正解なしでは決められないので、W=2を主とし、W=1・4を参考として出す（どれを選ぶかに正解を使わない）。
- p-bit方式は入れない（E4でBPと同着を確認済み。問いは「正解なしで網が効くか」なので）。

## 物差し・判定
- 物の主張（評価用）のAURCと、答える割合100・90・70・50%の正しさ。うその種類（G・H・E）ごとの正しさ。
- 推し量った「本当の割合」と、本当の値（候補中の正しい割合）の差。
- 判定：E4と同じ。差0.02以上で5回中4回以上同じ向き＝差あり。主に見る比べ：④対①、④対②、④対③、④対⑦、⑤対④、⑤対③、⑤対⑦。
- 正解なしの方法には学習用データがないので、5回の分け方で変わるのは評価する名詞だけ（方法の中身は5回とも同じ）。

## 先に書く予想（外れてもそのまま書く）
- ③（網なしの癖の推し量り）だけで、①より良くなる（いいえ寄りの癖がある程度直る）。
- ④は①・②に勝つ。④対③は④が勝つ（ルールが本当の割合の推し量りを助ける）。
- ⑦（癖消し）は①より良い。④・⑤が⑦に勝てるかは五分（ここが本当の勝負）。
- ④は大きな網なので、使い回す主張に疑いが積み重なり、E4-2ほどではないが崩れる。⑤は④より良い。
- 正解を使うE4-2の③（0.086）には、どれも届かない。

## 弱点
- データはE4-2と同じ（新しい分野ではない）。
- ルールの強さWは決め打ち。
- うそ候補の作り方にGemmaの答えを使っている（G）ので、①には不利な作り（E4-2と同じ）。

## 予定
1. コード e5.py（e42.pyの網を使う）。作り物の答えで通してから本番（Colab不要、私の作業場所で）
2. 結果を一言で報告 → 計画書の末尾に書く

## 結果（2026-11-09、e43.py、E43_results.json、log43.txt）
計画からの変更（結果を見る前、作り物の答えで気づいた）：網ありのEMで「本当の割合＝周辺確率の平均」をそのまま足すと、網の押しを二重に数えて分類どうしの主張が全部うそに倒れた。網ありの時は「Gemmaの答えを見ない網だけの模型で、種類ごとの平均がqの平均になる偏り」を合わせる形に直した（正解は使わない）。遅かったので、この合わせは毎回8歩まで（前回から続ける）。

物の主張のAURC（5回の平均、小さいほど良い）：
| 方法 | AURC | 全部答えた時の正しさ | 半分答えた時 |
|---|---|---|---|
| ① 自信 | 0.248 | 69.5% | 77.1% |
| ② 矛盾を数える（W=1） | 0.151 | 70.2% | 84.3% |
| ③ 網なしの癖の推し量り | 0.253 | 69.6% | 77.1% |
| ④ 正解なしの大きな網（W=2） | 0.157 | 73.1% | 81.0% |
| ⑤ 正解なしの慎重な網 | 0.168 | 80.1% | 84.4% |
| ⑥ 正解なしの小さな網 | 0.280 | 64.8% | 71.7% |
| ⑦ Batch Calibration | 0.243 | 69.2% | 76.1% |
| 参考 ④ W=1 / W=4 | 0.188 / 0.132 | | |
| 参考（正解を使う）E4-2 特徴＋学習 / 慎重な網 | 0.086 / 0.079 | | |

判定（差0.02以上で5回中4回以上）：④は①・③・⑦に勝ち（差約0.09、5/5）。④対②は同着（④が0.006悪い）。⑤対④は同着（⑤が0.011悪い）。⑤は③・⑦に勝ち。③対①、⑦対①は同着。⑥は①に負け。
推し量った本当の割合（本当の値）：物の主張 0.453（0.430）、両立しない 0.965（0.969）は近い。分類の一種 0.255（0.026）は大きくずれた。EMは50回で落ち着き切らない（最後の変化0.01）。
うその種類ごとの正しさ（全部答えた時）：本当 自信62%→④74%→⑤89%。G（Gemmaが一番信じたうそ）は 自信31%・④25%・⑤37%で、ほぼ直らない。

予想の答え合わせ：③が①より良い→外れ（同着。1つの答え手だけでは癖は決まらない）。④が①・②に勝つ→半分（①には勝ち、②とは同着）。④が③に勝つ→当たり。⑦が①より良い→外れ（同着、ずらしは約−0.36で小さい）。④・⑤が⑦に勝てるかは五分→勝った。⑤が④より良い→外れ（同着）。正解ありの0.086に届かない→当たり。

まとめ：正解がない場面では、網（④）はAIの自信や正解なしの癖消しにははっきり勝つ。ただし、同じルールで矛盾を数えるだけの②と同着で、網でまとめる上乗せは見えない。ルールの強さW=4は参考で0.132と②より良いが、Wを選ぶのに正解が要るので主張には使わない。
