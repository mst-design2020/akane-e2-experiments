# E14-2 計画：継ぎ足しの資料を Wikipedia の記事の最初の1文に替える（2026-11-13 朝、本人「やろう」）

きっかけ：E14・E14-1 で、継ぎ足しが効かなかった主な原因は一般的な文（GenericsKB）の雑音と、継ぎ足しの段の重なり。本人の経験（ASE は fastText の広告まじりの雑音を避けて Wikipedia から作った）と同じ考えで、資料を Wikipedia に絞る。

## 先行研究（追加分、E14_prior_work.md も）
- **Kazama & Torisawa 2007**（EMNLP-CoNLL）：Wikipedia の記事の最初の1文の「is/was/are/were」の後の名詞のかたまりの最後の語を上位語にする。one・kind・sort・type は次の名詞へ（語の一覧）。カテゴリは「きれいな上下関係ではない」として使わない。曖昧さ回避のページは飛ばし、転送はたどる。正しさの数字はなし。
- **WiBi（Flati ほか ACL 2014）**：同じく最初の1文の係り受けから上位語。1,000ページで語の正しさ 94.83%（再現 90.20%）、意味まで合わせると 82.77%。
- 違い：今回は語の一覧を使わず、文の中の名詞の候補から Gemma が「この文は X が Y の一種だと言っているか」で選ぶ。小さいAIの答えの点検の鎖の行き止まりに継ぐ。

## 変える所
- 継ぎ足しの資料：**Wikipedia の要約 API（page/summary）で取ったその語の記事の、要約の最初の1文**だけ。曖昧さ回避など、API の type 欄が standard でないページは使わない。転送はたどる（返ってきた文の主語が違えば捨てる）。カテゴリ（タグ）は使わない。一般的な文・自作文は使わない。
- 判定は E14-1 と同じく Gemma（"Does this sentence say that a X is a kind of Y?"）、親の意味選びも Gemma。辞書の段は NLI のまま。
- **継ぎ足しは1つの道で1回まで**（分析で数える。E14 で継ぎ足しの重なりがずれを生んだため）。段の上限は6のまま。

## 決まり（先に固定）
- 物差し・差の決め方は E14 と同じ（AURC、物の語で1,000回、相手の20%以上かつ95%幅が0をまたがない）。
- 主：⑭w1（Wikipedia、1回まで）対 ⑥N（700、常識 Claude）。確かめ：300。両方で良ければ旗「段不足を Wikipedia で埋められた（候補）」。
- 副：⑭w1 対 ⑥N6、⑭w（回数の上限なし）対 ⑥N、⑭w1 対 ⑭w、Gemini 判定。数え：正しい「いいえ」が「はい」になった数、間違った「はい」の増え、正しい「はい」を壊した数。継ぎ足しで「はい」になった50本を読む。

## 正直に書いておくこと
- この1,000問は E14・E14-1 で結果を見た問題。勝っても「候補」まで。主張には新しい問題での確かめが要る。
- Wikipedia にない語（一般名詞の多く、例：wearer）は継げない。Wikipedia の記事は固有の物（会社・作品）を指すことがあり、その時は意味がずれる（WiBi でも語と意味の正しさに12ポイントの差）。

## 予想（先に書く）
- 雑音は E14 より大きく減り、間違った「はい」の増えは小さい。ただ、Wikipedia の記事がない語・人を指す語（"One who" 型）の多くは継げず、埋まる正しい「いいえ」は E14 より少ない。
- ⑭w1 は ⑥N に 700 で同着か少し良い。20% の差に届くのは五分五分より下。
