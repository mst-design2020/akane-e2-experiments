# E11-3 先行研究：いろいろな確かめの手がかりを、学習で1つにまとめる（2026-11-12）

E11-2 で「いいとこ取り」（木の学習に、AIの自信・辞書の鎖・深い鎖・箱・意味選びの重みを全部入れる）が、決まりで初めて勝った。別の問いでも繰り返せるかを確かめる前に、近い研究を見た。

## 近い研究
- **Chauhan ほか（arXiv 2608.24492、When Do Supervised UQ Ensembles Improve LLM Hallucination Detection?）**：いくつもの「自信」の点数を、正解付きの少しの問題で学習してまとめると、一番良い1つの点数より良い（32条件中30）。100問ほどの正解でも効く。分布がずれると28条件中23で勝ち、5で負け。資料は使わない（AIの中だけの手がかり）。
- **Pawar ほか（NeurIPS 2026 workshop、Complementary Uncertainty Signals）**：意味のばらつきと単語の確率を学習で重ねると、7つのテスト×4モデルの「半分近く」で一番。「どの方法もいつも一番ではない」。
- **UniFact（Su ほか、arXiv 2512.02772、査読中）**：AIの中の手がかりと、外の資料での確かめ（Wikipedia）を足す（学習でなく決まった重み0.5）。Llama-3.1-8B では6つ中5つで一番の単独より良いが、Qwen2.5-14B では6つ中2つだけ。モデルが替わると崩れる。
- **EnsemHalDet（Miyazato ほか、arXiv 2604.02784）**：内部の値をたくさん重ねても、一番良い1つとの差は小さく、ばらつきの中のことが多い。
- **Knowledge Vault（Dong ほか 2014）・Snorkel（2017）**：いくつもの取り出し方・決まりの答えを、学習（または網）で融合するのは昔からの形。
- **自分の結果**：E10-2 の X++（Gemma の値に、辞書の説明文・一般的な文・NLI を足した木の学習）は、部分と全体で C++ に5回中5回勝っていた（0.065→0.042）。E10-1 の ⑧N++（鎖を足す）は3場面とも C++ と同着。E9n では「辞書は単独より、学習に足す材料として効く」。

## 分かること
- 手がかりを学習でまとめると良くなるのは、よく知られた形（積み重ね）。新しい方法ではない。
- ただし「いつも効く」わけではない：モデルや分野が替わると崩れる例がある（UniFact、Chauhan の5/28）。だから別の問いで繰り返すのは意味がある。
- 外の資料（辞書の鎖・箱・一般的な文）と、小さいAIの意味選びを、同じ学習に入れて、問いを替えて繰り返した例は見当たらなかった（調べた範囲）。
- 学習には正解付きの問題が要る。E10 系では WordNet の正解で学習し、常識の判定で採点している（学習と採点の正解が別）。
