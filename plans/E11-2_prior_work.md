# E11-2 先行研究：たどれない正しい答えを、深い鎖と箱のベクトルで埋める（2026-11-12）

前の調べ（plans/E11_box_dictionary_prior_work.md、約20本）に足した物。問い：E8（辞書の説明文＋Gemmaの意味選び）が「いいえ」と言ってしまう正しい組を、①鎖を深くする ②E8の組で学習した箱の形のベクトル、で埋められるか。

## きっかけ（E11-1 の数え、E8n 方法D、1,000問）
- 間違った「はい」65、正しい答えへの「いいえ」82。82のうち55は点数がほぼ0（分類まで着かない）。
- その55のうち45は、3段目の先にまだ説明文の頭の名詞がある（深くすれば先へ行ける）。10は3段より前で止まる。
- 例：bodybuilder→builder→person→human→individual→object→thing までは行くが、どの点からも「animal」に着かない（NLIが「人は動物の一種」と言わない）。深さだけでなく、着きの判定で落ちる物もある。

## 1. 形のベクトルで「推移の閉じ」を当てる
- **Vendrov ほか 2016（order embeddings）・Ganea ほか 2018（双曲の円すい、arXiv 1804.01882）**：WordNet 名詞（8.2万語・66万組）で、直接の親子（推移の簡約、basic）は全部学習に入れ、それ以外の組（non-basic）を0／10／25／50%足して残りを当てる。
  - テストF1（5次元／10次元）：order 34.4/43.0（0%）、70.2/69.7（10%）、81.7/84.1（50%）。双曲の円すい 29.2/32.2（0%）、80.1/85.9（10%）、92.8/94.4（50%）。
  - **直接の親子だけ（0%）で学ぶと、遠い組は3〜4割しか当たらない。** 正しい直接の親子だけなら、グラフをたどれば100%当たる。形のベクトルが役に立つのは、遠い組も一部学習に入る時。
- **Boratko ほか NeurIPS 2021（Capacity and Bias）**：箱は推移の閉じたグラフに特によく合う（WordNet 動物 4,017語・直接4,051組・閉じ29,795組）。ただし測ったのは「表せるか」で、見ていない組を当てる力ではない。辺の間違いも、グラフをたどる方法との比べもない。
- **Boratko ほか NeurIPS 2022（Binary Code Box）**：推移と輪を同時に表す。正しいグラフの話。

→ **箱が深い鎖に勝てるのは、辺に抜けや間違いがある時だけ**、と見るのが筋。E8 の辺は抜けも間違いもあるので、比べる意味はある。ただ、深い鎖は強い比べ相手。

## 2. 深くたどると崩れるか
- **E7（自分の結果）**：意味を選ばずに2段以上たどると、道の6割が意味の取り違え（person＝体の一部など）。E8 で途中の意味を Gemma が選ぶと取り違えは約1割（一覧なしで72→10%）。
- **Gupta ほか 2017（Taxonomy Induction using Hypernym Subsequences、arXiv 1704.07626）**：上位語の並びを長くすると、正しさが下がり拾える数が上がる（図のみ、ずれのため）。一般的な語ほど型で取った上位語の正しさが下がる（Velardi ほか を引く）。長さは4までに切っている。
- **OntoLearn Reloaded（Velardi ほか 2013）・MindNet（1998）**：説明文から上位語を繰り返したどると意味がずれる、とずっと言われている（E7 の先行調べ）。
- **Ustalov ほか 2018**：意味を付けて広げると拾える数は上がるが正しさは下がる（英語 precision 64.8→53.2%）。

→ 深くすると「いいえ」は減るが、間違った「はい」が増えるはず。どちらが勝つかが測る所。予想は E7 から「崩れる側」。

## 3. 小さいモデル＋形の決まり
- **SS-MONO（ICLR 2026、Geometric Constraints for Small Language Models…）**：小さいモデルに双曲の円すいの決まりを足すと、分類表の拡張で大きいAIより良い。組を直す話ではない。
- **TaxoBell（WWW 2026）・BoxTaxo（WWW 2023）・HyperBox（LREC 2022）**：箱で分類表に語を足す。どれも正しい分類表で学習する。
- **箱を間違いのある組で学習した時の強さを測った研究は、今回も見つからなかった**（前の調べと同じ）。

## 4. 似た「抜けを埋める」の話
- **Roller ほか 2018、Le ほか 2019**：ノイズのある型の組をベクトルにすると、主に抜け（recall）が埋まる。
- **Gao・Metaxas ICML 2026（INSES、arXiv 2603.14006）**：知識グラフの抜けを、似ている点への「仮の辺」で埋めると答えが良くなる（MuSiQue +0.12 など）。分類の話ではなく、形のベクトルでもない。

## 空いている所（調べた範囲）
- 辞書の説明文＋小さいAIの意味選びで作った辺について、深くたどる場合と、形のベクトルで埋める場合を、同じ問題で比べた例は見当たらない。
- 深くたどると、意味選びありでも崩れるかを、段ごとに測った例も見当たらない（E7 は意味選びなし）。
- 新しい方法とは言わない。「E8 の弱点（遠い分類に届かない）を、安いたどりと形のベクトルのどちらで埋めるとよいか」の確かめ。

## この案への見立て
- 深い鎖：45/55 は先に進めるので、「いいえ」は減る見込み。ただ間違った「はい」も増える（E7 の6割ほどではないが）。差し引きは五分。
- 箱：Ganea の0%の数から、E8 の直接の辺だけで学ぶ箱は、深い鎖より弱い見込みが高い。箱が勝つとしたら「着きの判定の抜け」（person→animal のような所）を、似た語から埋める時だけ。見込みは五分より下。
