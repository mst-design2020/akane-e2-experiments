# E17 計画：TADORI を、人が点を付けた公開データ（HyperLex）で測る

2026-11-14 6:28 本人「よし、ではそれをやろう…進めてほしい」。結果を見る前にここで固定する。先行研究：E17_先行研究.md。

## 問い
今までの「常識の正解」はAI（Claude・Gemini）が付けた。人が点を付けた HyperLex でも、
1. 小さいAI（Gemma-2 2B）の答えに TADORI を足すと、人の点に近づくか。
2. 2B＋TADORI は、同じ聞き方の大きなAI（Gemma-2 9B）にどこまで近づくか。

## データ
- HyperLex 名詞 2,163組（X, Y, 人の平均点 0〜6）。Colab で原本（github ivulic/hyperlex）から取る。データはリポジトリに入れない。
- 公式の乱数の分け方：学習 1,514・確かめ 108・試験 541（名詞）。

## 方法（どれも HyperLex で学習しない物が主）
- G2：Gemma-2 2B に `Is a "X" a kind of "Y"? Answer Yes or No only.`（E15 の none と同じ）。値は Yes−No の logit。
- G9：Gemma-2 9B に同じ問い（参考：大きなAI）。
- T：TADORI（E8n の一覧なしの鎖、3段、親の語は NLI、途中の語の意味は Gemma 2B、最後の段は NLI。E15 の n_nli と同じ）。点＝道の強さ×着き の一番大きい物。X の辞書の見出しが無い組は鎖なし。
- S（TADORI の普段の使い方、学習なし）：鎖がある組は T、無い組は σ(G2)（E10-1 の ⑥N と同じ形）。
- 学習あり（副）：HistGradientBoostingRegressor（E9 以来の木の学習）で人の点を当てる。学習＝学習＋確かめの 1,622組、試験＝541組、種5つの予想の平均。
  - LG2：[G2]、LG2T：[G2, T, 鎖があるか, 一番強い道の段の数]、LG9：[G9]（参考）。
- 参考（主の比べに入れない）：WordNet で Y が X の上位語か（組の選び方が WordNet なので有利）。Colab の nltk で計算。

## 物差し
- 主：人の平均点との順位の合い方（スピアマンの ρ）。95%の幅は組を引き直す2,000回。
- 副：人の点 3 以上（0〜6 の真ん中）を「一種」とした時の AUROC。種類ごと（一種1〜4段・逆向き・同じ仲間・部分・同義・反対・無関係）の平均値（見るだけ）。

## 決まり（先に固定）
- 旗A（主、学習なし、名詞 2,163組）：ρ(S) − ρ(G2) ≥ 0.05 かつ 95%の幅が0をまたがない → 「人の点でも TADORI は効く」。ρ(S) < ρ(G2) で幅が0をまたがない → 「人の点では悪くなる」。それ以外は同着。
- 旗B（副、学習あり、試験541組）：ρ(LG2T) − ρ(LG2) について同じ決まり。
- 9B との比べ（旗C）：ρ(S) − ρ(G9)（2,163組）と ρ(LG2T) − ρ(LG9)（541組）。95%の幅が0より上 → 「9Bより上」、0をまたぐ → 「9Bと同着」、0より下 → 「9Bに届かない」。
- 見込み（先に書く）：HyperLex には「部分」「同じ仲間」など中くらいの点の組が多く、0/1 寄りの TADORI は順位の合い方で不利かもしれない。旗Aは同着の見込みもある。

## 結果（11-14 7:32、v2＝ドライブなしで流した。値は results/E17_summary.json）
- 学習なし（2,163組、人の点との順位の合い方 ρ）：2B 0.832、9B 0.852、TADORI 0.782、S（TADORI＋無い所は2B）0.795。
- **旗A：悪くなる**（S−2B −0.037、幅 −0.054〜−0.021）。**旗C：9Bに届かない**（S−9B −0.057）。
- 学習あり（試験541組）：LG2 0.810、LG2T 0.824、LG9 0.835。**旗B：同着**（+0.014、幅 −0.007〜+0.034）。LG2T 対 LG9 は 9Bと同着（−0.011、幅 −0.036〜+0.015）。
- 見るだけ（種類ごと、結果の後の見方）：TADORI は「部分」（人1.9点、2B 0.63→T 0.27）、「逆向き」（人2.0点、2B 0.44→T 0.12）、「同じ仲間」で「はい」を大きく減らす。代わりに本当の一種（人4.8〜5.2点、2B 0.94〜0.97→T 0.85〜0.91）と同義（人4.0点、0.93→0.68）も下げる。
