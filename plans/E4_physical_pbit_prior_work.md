# 次の方向（案）：確率で推し量る計算を、物理のゆらぎ（p-bit）に解かせる — 先行研究

## 近い先行研究
### p-bitの機械で、難しい問題を解く（谷の避け方つき）
- **Nikhar, Kannan, Aadit, Chowdhury, Camsari「All-to-all reconfigurability with sparse and higher-order Ising machines」Nature Communications 15, 8977 (2024)**（arXiv 2312.08748 の査読版）
  - FPGA（Xilinx Alveo U250）でp-bitの機械。3-XORSAT（論理の問題）を、2つ組の結合と **3つ組の結合（高次）** の両方で解く。
  - 谷にはまる対策は **温度の違う鎖を並べてときどき入れ替える（適応的パラレルテンパリング）**。「入れ替えがあれば永久にははまらない」。
  - 速さ：1回全部揺らすのに66.67ナノ秒。一番速いGPUの貪欲法には「まだ及ばない」と本人たちが書いている。磁石の素子（sMTJ）なら1ナノ秒・100万個の見積もり。
  - → E4の網（3つ組のルール）は、この機械の形にそのまま乗る。違い：解いているのは論理パズルで、AIの記憶の確かめではない。
- Aadit, Çamsarı ほか 2026（arXiv 2606.25313）：FPGA18基で100万p-bit。

### 素子のばらつき
- **Kaiser, Borders, Camsari, Fukami, Ohno, Datta「Hardware-aware in situ Boltzmann machine learning using stochastic MTJs」Phys. Rev. Applied 17, 014016 (2022)**：磁石の素子（東北大）で、素子ごとのばらつきを「その場で学習して重みを合わせる」ことで打ち消す。全加算器の学習。
- Zheng ほか 2026（arXiv 2602.07037）：MTJのゆらぎを、ベイズの「分からなさ」の材料として使うスパイキングネット（画像分類）。

### 熱力学コンピュータ（ゆらぎ入りの微分方程式＝ランジュバン）
- **Aifer ほか（Normal Computing）「Thermodynamic Bayesian Inference」arXiv 2410.01793 (2024)**：アナログ回路のランジュバンの動きで、ベイズの事後分布をサンプリング。時間は次元の対数で増える見積もり。シミュレーションのみ。連続値（ガウス）向けで、○×の網ではない。
- Extropic Z1（2026-09）：約27万p-bit、比べは文章を作るモデルの電力のみ。

### ロボット・端末で確率の計算
- **Darabi ほか「Navigating the Unknown: Uncertainty-Aware Compute-in-Memory Autonomy of Edge Robotics」arXiv 2401.17481 (2024)**：昆虫サイズのドローンの位置推定を、CMOSの電流のゆらぎでベイズ計算。ロボットへの応用の例。知識の確かめではない。

## 空いていそうな所（推測）
- 「AIがためこんだ記憶の網（○×の主張と論理のルール）」を、**p-bitの機械と同じ制約（ばらつき・粗い重み・高次の結合・つながりの上限・テンパリング）** で解いたら、正しさと「分からない」の出し方が普通の計算（BP）と比べてどうなるか。見つけた先行研究は、論理パズル（XORSAT）か、学習（ボルツマンマシン）か、連続値のベイズで、AIの記憶の確かめはなかった。
- ロボットへの応用は「その場の位置推定」が中心で、「AIの言ったことのつじつまを、電力の少ない機械の中で確かめる」ものは見つからなかった。

## できそうな実験（案、E4-1の結果を見てから決める）
1. E4-1の網を、本物のp-bitに近い形で揺らす：重みを数段階に丸める、素子ごとのばらつき（偏り・感度）を入れる、テンパリングで谷を避ける。BPと比べて正しさがどこまで保てるか。（手元で可能）
2. つながりの上限（1つの素子に十数本）を守るため、使い回される主張（最大約1,000本）を「写し」に分ける作り方を試し、それでも答えが崩れないか。（機械の制約そのもの）
3. 電力と時間の見積もり：先行研究の数字（FPGA 1回66.67ナノ秒、sMTJ 1ナノ秒・約2フェムトジュール見積もり）と、普通の計算機のBPを比べる。（見積もりであって測定ではない、と書く）
