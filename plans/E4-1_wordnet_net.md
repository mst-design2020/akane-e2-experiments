# E4-1 計画（案）：AIの記憶の大きな網で、網は単純なやり方に勝てるか

2026-11-09 案。雅也さんの了承待ち（了承後、結果を見る前に固定）。先行調査 E4_先行研究.md、下見 PLAN_E4-0.md。

## 問い
1. Gemmaが答えた何千もの「〜は〜の一種か」を、1つの大きな網（輪がとても多い）にすると、AIの自信・矛盾を数える・特徴＋学習より、うそを見分けて控えるのが上手になるか
2. 「1問ずつの小さな網（普段の確かめ）」と「全部をつないだ大きな網（熟考）」で差が出るか ← AKANEの方針（熟考の時だけ大きな網）をそのまま確かめる
3. 大きな網で、BPとp-bit方式の答えが分かれるか（E4-0では同着）

## データ（WordNet、手元で作れる）
- Wikidataは私の作業場所からはつながらない（Colabからなら取れる）。WordNetは取れるので、まずWordNetで作る。
- 物：よく使う一語の名詞で意味が1つのもの（例 robin, hammer）約1,500個。分類：中くらいの分類 約60個（animal, bird, tool, vehicle, food, furniture …）。
- Gemmaに聞く主張（全部 はい/いいえ。はいの確からしさを使う）
  - 物の主張：「robin は bird の一種か」。物ごとに正しい分類を最大4つ、関係ない分類を3つ。約8,000問。
  - 分類どうしの主張：「bird は animal の一種か」「tool と weapon を両方満たす物はあるか（両立しないか）」。物の間で使い回す。約5,400問。
- 正解：WordNetの階層から（Gemmaの答えとは別）。分類どうしの「両立しない」は、WordNetで共通の下位語がないことで決める。

## 網
- ルールは論理の形だけを固定し、中身の分類の知識はGemmaの答え（主張）として網に入れる。
  - 受け継ぎ：「Xはaの一種」かつ「aはbの一種」なら「Xはbの一種」
  - 両立しない：「aとbは両立しない」なら「Xはa」と「Xはb」は同時に成り立たない
- 試しに作った形（e41_shape_draft.py）：主張 13,387・ルール 46,890・全部が1つにつながる・輪の数（独立な輪）約80,000。分類どうしの主張には最大957本のルールがつながる（「bird は animal の一種か」が多くの物で使い回されるため）。
  - E2・E3の網（ほぼ木）とは桁違いに輪が多い。
  - 注意：p-bitの機械はつながりが少ない網（1つに十数本）向き。957本の主張は機械向きでない。これも結果に書く。

## 比べる方法
① Gemmaの自信だけ
② 矛盾を数える（破れるルールの数で直す）
③ 特徴＋学習（自信、周りの主張の自信、破れるルールの数など。物ごとに分けて5分割）
④ 小さな網（物ごとに、分類どうしの主張を複製して1問ずつ別の網に。小さいので正確に計算）＝普段の確かめ
⑤ 大きな網＋BP＝熟考
⑥ 大きな網＋p-bit方式（E4-0の弱点を受けて鎖4本、1万回。β=1）
- ルールの強さ：物の2割（調整用）で1つの値を決め、④⑤⑥で同じものを使う。評価は残りの8割。「信じすぎ（2倍）」も参考に出す。

## 測り方
- 物の主張の、答える割合（100・90・70・50%）ごとの正しさとAURC。分類どうしの主張も別に出す
- 5分割。差0.02以上で5回中4回以上同じ向きなら「差あり」
- BPが収まったか、BPと⑥の確率の差
- Gemmaの答えを手元に持ってきてから、網の計算は全部私の作業場所で（Colabは答えを取るだけ）

## 先に書く予想（外れてもそのまま書く）
- ⑤大きな網は①自信より上、ただし差は小さい（Pujara 2013は+0.03）。
- ⑤大きな網と④小さな網の差は小さい。差が出るとしたら、分類どうしの主張（使い回される所）。
- ⑤BPと⑥p-bit方式は同着。
- ③特徴＋学習が⑤に並ぶか勝つこともありうる（E3のように）。

## 弱点
- WordNetの分類の癖（例 tomato は fruit か vegetable か）で正解が揺れる。50件を目で確かめて記録する。
- 正しい分類・関係ない分類の選び方がWordNet頼み（関係ない分類はかなり明らかなものになりやすい）。
- 小さなAI（Gemma 2B）1つ、1分野。

## 予定
1. 了承をもらったら固定し、データ作り（私）
2. Colabノートを作る（Gemmaに約13,400問。L4で数十分の見込み）→ 雅也さんに実行してもらう
3. 答えのJSONを読んで網の計算と比べ（私）→ まず一言で報告

## 固定（2026-11-09 21:27 JST 雅也さん「いい」。細かい決め方はここで固定し、Gemmaの答えを見る前に変えない）
### データ（e41_data.py → e41_data.json、SEED=0）
- 分類46個（WordNetの見出しを指定。WordNetの癖で正解がずれやすい vertebrate／invertebrate（WordNetでは person が脊椎動物の下にない）、covering、structure は外した）。
- 物：一語・小文字・名詞の意味が1つ・wordfreq 2.5以上・分類のうち2つ以上に入るもの。くじで1,500個。
- 物の主張「Robin is a type of bird.」：正しい分類を最大4つ（くじ）、関係ない分類を3つ（正しい分類のどれとも下位語を共有しないもの）。
- 分類どうしの主張「Bird is a type of animal.」（同じ物の候補どうしの全ての向き）、「Nothing can be both a tool and a weapon.」（一種の関係でない組）。
- 数：主張 10,864（物 7,906・本当43%／分類の一種 2,008・本当3%／両立しない 950・本当98%）。ルール 51,643（受け継ぎ34,106・両立しない14,633・逆向き不可1,004・一種なら両立する1,900）。正解が破るルール 0。
- 正解の目視（Claude、物の主張50件）：正解の付け方はWordNetの意味どおり。ただし普段と違う意味の語が約6件（Whitey, Anti, Longer, Maxi, Erica, Uke など。名詞の意味が1つでも、普段は別の品詞や固有名詞で使う語）。人を表す語が多い（WordNetの特徴）。分類どうしの主張は本当/うそが大きく偏る（3%・98%）ので、主に見るのは物の主張。

### 網（エネルギー）
E = −λ Σ (Gemmaの はい−いいえ の値)×x − … ではなく、主張ごとの場 = λ×（はい−いいえ のlogit）/2、ルールは破れたら W の罰。ルールの形は4つ（上の通り）、W は全部共通。
- ④ 小さな網：物ごとに、その物の主張＋その物で使う分類どうしの主張の「写し」＋その物のルールだけで網を作る（使い回しなし）。BPで解く（小さいが輪はあるので正確な計算は重い→計画の「正確に計算」をBPに変更）。
- ⑤ 大きな網：全部の主張・全部のルールを1つに。BP（揺れ抑え0.5、最大500回）。
- ⑥ 大きな網＋p-bit方式：鎖4本、各1万回（はじめの1割を捨てる）、β=1、色分けごとに同時に揺らす。
- ② 数える：①の答えを周りに置いたとき、その主張を本当にすると破れるルールの数と、うそにすると破れる数の差 × W を場に足す（1回）。
- ③ 特徴＋学習：logit、②の2つの数、物の他の主張のlogitの最大と平均、分類どうしの主張のlogit（関係するものの平均）、主張の種類。ロジスティック回帰。
### 分け方と調整
- 物を5通りにくじで分け、それぞれ2割を調整用、8割を評価用。λ∈{0.25,0.5,1,2}、W∈{0.5,1,2,4,8} を、調整用の物の主張のAURCが一番小さくなるもの（④⑤は⑤のBPで決めた同じ値、⑥も同じ値）。③は調整用で学習、評価用で評価。
- 評価は評価用の物の主張（主）。分類どうしの主張は全物共通なので参考（調整用にも使われる）。
- 「信じすぎ」：決めたWの2倍でも⑤⑥を出す（参考）。
### 判定
- AURC：差0.02以上で5回中4回以上同じ向き＝差あり、それ以外は同着。主に見る比べ：⑤対①、⑤対③、⑤対④、⑤対⑥。
### Gemma
- gemma-2-2b-it、聞き方は E2-3 と同じ（"Is the following statement true? Answer Yes or No only.\nStatement: …"、Yes と No のlogitの差）。Colabは答えを取るだけ。網の計算は私の作業場所で（e41.py）。

## 結果（2026-11-09 22:48 JST、Gemma-2 2B、5分割。E41_results.json・log41.txt、計算 e41.py 4,187秒）
Gemmaの答え（E41_gemma-2-2b-it.json）：物の主張の正しさ 81.8%（「はい」と言う割合 28.8%、本当は43%＝「いいえ」に寄っている）。分類の一種 95.6%、両立しない 94.9%。

物の主張（評価用8割）のAURC（小さいほど良い）、5回平均：
| 方法 | AURC | 全部答えた正しさ | 半分答えた正しさ |
|---|---|---|---|
| ①Gemmaの自信 | 0.142 | 81.9% | 88.3% |
| ②矛盾を数える | 0.053 | 82.0 | 97.7 |
| ③特徴＋学習 | **0.009** | 93.6 | 99.8 |
| ④小さな網（1問ずつ、BP） | 0.059 | 81.6 | 96.1 |
| ⑤大きな網（BP） | 0.062 | 82.3 | 95.5 |
| ⑥大きな網（p-bit方式、鎖4本・1万回） | 0.080 | 82.3 | 93.9 |
| ⑤信じすぎ（2W） | 0.063 | | |
| ⑥信じすぎ（2W） | 0.079 | | |

判定：⑤は①に勝ち（差0.080、5/5）。⑤と④は同着（差0.003）。⑤と⑥は同着（差0.018。1回目だけp-bit方式が谷にはまり0.144、残り4回は確率の差0.001でほぼ一致）。⑤は③に負け（0/5）。⑤と②は同着。BPは全部収まった。調整で選ばれた値 λ=1〜2、W=4〜8（強い）。
分類どうしの主張（参考）：網に入れると Gemmaだけより悪くなった（一種 0.011→0.021、両立しない 0.009→0.063）。使い回される主張に、たくさんの物から小さな疑いが積み重なって倒れる（作り物の答えで見た現象が本物でも起きた）。

予想との比べ：⑤は①より上（予想どおり、ただし差は予想より大きい）。⑤と④の差は小さい（予想どおり）。⑤と⑥は同着（予想どおり）。③が勝つ（ありうると書いたとおり）。

### 追加の確かめ（計画になかったもの。結果を見たあとに行ったので、参考扱い）
- ③が強い理由（probe_learn.py、分け方0）：Gemmaの値だけを学習で合わせ直すだけで 0.143→0.091（「いいえ」に寄った癖を直すため）。これに②の2つの数（本当にすると破れるルール数・うそにすると破れる数）を足すと 0.022。網の情報を、学習で重みを付けて使うと一番強い。
- 網に「いいえ寄りの癖を直す ずらし」を足した場合（probe_bias.py、5分割、ずらしは調整用で選択、上限4で頭打ち）：自信＋ずらし 0.086、大きな網 0.035、小さな網 0.022。ずらしを入れると網は良くなるが、③(0.009)には届かず、小さな網のほうが大きな網より良い。
- 弱点：うその分類を「正しい分類と下位語を共有しないもの」から選んだので、ルールで見分けやすい作りになっている（③と②が強く出る一因の見込み）。

### まとめ（一言）
本物のAIの記憶の大きな網（輪 約8万）でも、BPとp-bit方式は同着、大きな網と1問ずつの小さな網も同着だった。網はGemmaの自信よりはっきり良いが、網の情報を学習で使うやり方に負けた。使い回される分類の知識は、大きな網に入れるとかえって悪くなった。
