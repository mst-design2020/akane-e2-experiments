# E2-10 BTPropと同じテストで比べる（計画・2026-11-08 固定）

## 何を確かめるか
BTProp（Hou ほか NAACL 2025, github UCSB-NLP-Chang/BTProp master）は、ChatGPTに作らせた「信念の木」（言い換え・分解・論理関係・作り変え）と、NLIでつけた関係、ChatGPTのTrue/Falseの自信を、隠れマルコフ木（関係は絶対に正しい扱い、自信の出方は表で固定）で計算する。
問い：**同じ木・同じ自信・同じ関係で、私たちの「ルールも疑うBP」（関係を強さWで弱く信じ、強さと自信の重みλを20%で調整）にすると、BTPropより嘘を見つけられるか。**

## データ
- FactCheckGPT（Factbench.jsonl の source=factcheckgpt、github yuxiaw/Factcheck-GPT）94回答・678主張、True/Falseの631主張（嘘159）。
- 木・自信：BTPropが公開した logs/belief_trees/factcheckgpt_chatgpt.json と logs/conf_estimation/factcheckgpt_chatgpt.json（ChatGPT＝論文と同じ）。
- WikiBio（wiki_bio_gpt3_hallucination、HFのみ）：ラベルが取れたら同じやり方で追加（BTPropは前120人で自信の表を作っており、評価は121人目以降）。

## 比べる方法（全部同じ木の形。木はBTPropのコードと同じ手順で組む）
1. AIの自信（ChatGPTのP(True)）
2. BTProp（公開の設定 configs/hmm.yaml のまま）
3. ルールを全部信じるBP（W=20、λは調整）
4. ルールも疑うBP（W∈{0.5,1,2,4}、λ∈{0.5,1,2}、作り変え文の弱い場（自信なし）b∈{0,0.5,1}を調整）
- 木なので計算は厳密（数え上げと同じ）。p-bitは同じ答えになるので省く。
- 関係：entail→「親が○なら子も○」、neutral-entail→「子が○なら親も○」、entail-entail→両方、contradict を含む→「両方○はない」、分解→「親○⇔子が全部○」、neutral-neutral は捨てる（BTPropと同じ）。

## 測り方・合格
- 嘘（ラベルFalse）を見つけるAUROC。点は 1−（○の確率）。
- 回答ごとに分けて20%を調整用、残り80%で評価。5通りの分け方（くじ0〜4）。BTPropと自信は調整なしだが同じ80%で測る。
- 勝ち＝平均で0.02以上、かつ5回中4回以上上。0.02未満は同着。
- 主な比べ：4 対 2。ほか 4 対 3（疑う効き目）、2 対 1（BTPropの再現）。

## 言えないこと
- 木はChatGPTが作ったもの。Gemmaの話ではない。
- BTPropは調整なし（別のデータで作った表）、私たちは20%で調整している。差の一部は調整の差かもしれない→「私たちの網にBTPropの表を入れたもの」も参考に出す。
- BTPropのコードにはライセンス表示がないので、リポジトリにはコードを入れず、cloneして使う手順だけ置く。

## 結果 FactCheckGPT（2026-11-08、E210_factcheckgpt.json、5通りの平均AUROC）
- AIの自信 0.746／BTProp（公開コードどおり）0.780／BTProp（木がない48主張は自信を使う）0.793／ルールを全部信じるBP 0.807／ルールも疑うBP 0.801／疑うBP＋BTPropの表 0.795。
- BTProp対自信 +0.034(5/5)＝論文の再現（論文は+3〜9）。
- 疑うBP対BTProp(公開) +0.021(4/5)＝基準上は勝ち。ただし差のほとんどは、BTPropの公開コードが「木の無い主張」を確率1（本当）にしている所から。そこを直したBTPropとは +0.007(4/5)＝同着。
- 全部信じるBP対BTProp(直し) +0.014(5/5)＝同着（毎回上だが0.02未満）。疑う対信じる −0.006(2/5)＝同着：このテストでは疑う効き目が見えなかった（E2-9・Snorkelと同じ形）。※当初「NLIの関係はほぼ正しいから」と書いたが、これは確かめていない推測だった。2026-11-09に100組を目で確かめると、元の関係との一致は64/100（「含む」と「矛盾」の入れ替わりは2〜3組で、ずれの多くは「矛盾」か「どちらとも言えない」かの線引き）。この判定もAI（Claude）が付けたもの。
- 答え：同じテストで、私たちのBPはBTPropと同じくらい。上回るとは言えない。

## 結果 WikiBio（2026-11-08、E210_wikibio.json）
- 正解：HFの wiki_bio_gpt3_hallucination（本人がColabで取得、E2-10_wikibio_labels.json）。BTPropの評価文は代名詞を名前に置き換えた非公開の形なので、公開の hmm_posterior.json の文の順と生の文を似かたで並べて合わせた（align_wikibio.py、929文中924文、似かた中央値0.94）。評価921文・嘘672。
- AIの自信 0.727／BTProp 0.804（+0.076・5/5、論文の改善幅と同じくらい）／全部信じるBP 0.773／疑うBP 0.768／疑うBP＋BTPropの表 0.769。
- 疑うBP対BTProp −0.036（0/5）＝**BTPropの勝ち**。疑う対信じる −0.005＝同着。私たちのBPも自信よりは+0.040（5/5）。
- 参考（計画外）：調整の幅を広げても上がらない（0.757）。分解の扱いをBTPropと同じ「親が×なら子の組は等しくありうる」形にすると信じるBPは0.780まで上がるが、まだ−0.023。WikiBioの木は分解1,436組（FactCheckGPTは0）で、分解のある木ほどBTPropの作りが効く。BTPropの表はWikiBioの前120人で作ってあり、同じ所の有利もある。

## まとめ
- FactCheckGPT：同着。WikiBio（論文の本命）：BTPropが上。私たちのBPはBTPropより良いとは言えない。
- ルールを疑う働きは、このテストでは出番がなかった（E2-9・Snorkelと同じ）。理由を「関係がほぼ正しいから」とするのは推測（上の※）。

# E2-11 つながりをわざと外す（計画・2026-11-08 固定、結果の前）
- 問い：BTPropの木のNLIのつながりを0/1/2/3/5割くじで反対にすると、「つながりは絶対に正しい」BTPropは崩れ、疑うBPが上回るか。
- 外し方：NLIでつけたつながり（作り変え・論理関係の枝）だけを反転。含む→「両方○はない」、矛盾→「両方とも同じ」。分解の枝はNLIを使わないので触らない。くじは分け方ごとに変える（分け方番号を種に、枝ごとに決める）。BTPropと私たちのBPは同じ外れた木を使う。
- 私たちのBPは、外れた木のまま20%で強さと重みを合わせる（外れの量は教えない）。BTPropは公開の設定のまま。
- 比べ：疑うBP 対 BTProp、疑うBP 対 信じるBP。勝ちの基準はE2-10と同じ（平均0.02以上・5回中4回以上）。両データ（FactCheckGPT・WikiBio）。
- 先行の似た話：Safe-ABL（不正確なルールの数を変える）、Snorkel（情報源の正確さを学ぶ利点は中くらいの正確さで最大）、ConCoRD（NLI関係に重み）、私たちのE2-9（疑うのは保険、3割で疑わない網を逆転）。
- 予想：外れが増えるとBTPropは自信より下まで落ち、疑うBPは自信の近くで止まる。3割前後で逆転。
