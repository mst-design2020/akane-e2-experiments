# E20 計画：説明文に答えが書いていない所で、辞書の鎖（TADORI）は効くか

2026-11-14 13:51 本人「やってくれ」。先行：E20_先行研究.md。案：PLAN_E20_案.md。結果を見る前にここで固定する。

## 問い
X の辞書の説明文（最初の3つ）に分類の語 Y がそのまま書いていない「一種」の組で、
「説明文を見せて聞く（S）」に鎖（T）を足すと良くなるか。Gemma 以外の小さいAIでも同じか。人が作った公開の正解（SemEval-2018 Task 9）でも同じか。

## データ
- **W（主）**：E19 と同じ作り（WordNet 名詞、小文字 a〜z 3文字以上、46分類のどれかの下、Wiktionary に名詞の見出し、wordfreq の zipf で よく出る ≥3.0・中 1.5〜3.0・珍しい <1.5）。**E19 の 600 語（種0）を除いて、種1で各段 200 語**。600語×46＝27,600組。正解は WordNet（E19 と同じ）。
- **E（公開の正解）**：SemEval-2018 Task 9 英語（1A）のテスト語と人が作った上位語（主催者の配布 zip、CRIM の取得スクリプトと同じ所）。X は小文字 a〜z 3文字以上の1語で Wiktionary に見出しがある語。「はい」＝その語の正解の上位語から最大3つ（種0）。「いいえ」＝他の語の正解の上位語から、その語の正解に無い物を同じ数（種0）。珍しさは同じ3段。語ごとに種0で半分に分け、半分でしきい値、残り半分で測る。データはリポジトリに入れない。
- **書いていない組**：X の最初の3つの説明文（小文字）に、Y が語として（複数形 s・es も）出ない組。主の物差しは「一種でない組すべて＋書いていない一種の組」で取る。

## 方法（小さいAI 3つ：Gemma-2 2B it、Qwen2.5 3B Instruct、Llama-3.2 3B Instruct（HF の許可が無ければ Phi-3.5 mini）。参考：Gemma-2 9B it）
- G：説明文なしで聞く Yes−No（E19 と同じ聞き方）。9B は G だけ。
- S：X の説明文を最初の3つまで見せて聞く Yes−No（E19 と同じ）。
- T：TADORI の点（E19 と同じ作り：親の語は NLI、3段、最後は NLI）。**途中の語の意味選びはそれぞれのAI**（Gemma は E19 と同じ）。
- **SO（主）：S > θ または T ≥ τ**（説明文を見せた上で、鎖で届けば「はい」）。TO：G > θ または T ≥ τ（E19 と同じ、参考）。
- SA（いつ使うか）：S > θ、ただし S が θ から m 以内の時だけ T ≥ τ も見る（AIが迷った時だけ鎖）。
- しきい値：W は「よく出る」段の全部の組、E は半分の語で、釣り合った正しさ（BA）が一番の所。SO は θ・τ を一緒に、SA は θ・τ・m を一緒に（5〜95% の 19 点ずつ）。

## 物差し
- BA（½×一種で「はい」の割合＋½×一種でないで「いいえ」の割合）。95% の幅は X の語ごとに引き直し 2,000 回。

## 決まり（先に固定）
- **旗1（主、W、書いていない組、3段まとめて）**：SO − S ≥ 0.03 で幅が 0 より上 →「効く」、差 < 0 で幅が 0 より下 →「悪くなる」、それ以外は「同着」。AIごとに出し、**3つのうち2つ以上で「効く」なら「鎖は説明文1段で届かない所に効く」と言う**。
- 旗2（E、測る半分、書いていない組）：旗1と同じ決まり。2つ以上で「効く」なら「人が作った公開の正解でも効く」。
- 旗3（いつ使うか、W、書いていない組）：SA − SO ≥ −0.01 で幅の下が −0.03 より上、かつ鎖を見た組が半分以下 →「迷った時だけ鎖で足りる」。
- 副：段ごと（よく出る・中・珍しい）の旗1、書いてある組を含めた全部、9B（G9）との差。
- 予想（外れたら書く）：よく出る・中の段で効く、珍しい段は同着（E19 点検5）。

## 常識での確かめ（[[feedback-claim-after-common-sense]]）
- 主の組（W・E それぞれ）で、どれかのAIで SO と S の答えが違う組だけを、方法を伏せて Claude・ChatGPT・Gemini が判定（各最大 800 組、種0）。正解をそれぞれと多数決で置き換えて旗をもう一度出す。
- 正解表と多数決の両方で同じ向きの時だけ結論を書く。判定はAI（人ではない）と書く。

## 結果（11-14 夕方）

流したもの：Gemma-2 2B・Qwen2.5 3B・Phi-3.5 mini（Llama 3.2 3B は使う許可がなく、計画どおり Phi に替えた）、参考に Gemma-2 9B（説明文なし）。値 results/c20.json、正解表の結果 results/out_noCS.json。
常識判定：主な組で SO と S の答えが違う組 1,044組（W 800・E 244）を Claude・ChatGPT・Gemini に判定させ、多数決も作った（results/judge/、judge_combine.py、summary_judges.json）。人の判定ではない。
正解表との一致：Claude 0.898・ChatGPT 0.842・Gemini 0.852・多数決 0.894。AIどうし 0.83〜0.87。

主な組（説明文の頭3つに分類の語がそのまま出ない組）、BA の差（SO−S、2,000回の組み直し、基準 0.03）：

| | 正解表 | Claude | ChatGPT | Gemini | 多数決 |
|---|---|---|---|---|---|
| 旗1 W 全部 | 1/3 | 1/3 | 1/3 | 2/3 | 1/3 |
| W よく出る | 3/3 | 3/3 | 3/3 | 3/3 | 3/3 |
| W 珍しい | 0/3 | 0/3 | 1/3 | 1/3 | 1/3 |
| 旗2 SemEval | 0/3 | 0/3 | 0/3 | 0/3 | 0/3 |

- 旗1：言えない（4つの判定のうち3つで 1/3）。効いたのは Gemma 2B だけ（+0.06）。Qwen +0.02〜0.04、Phi +0.01〜0.03。
- よく出る語：3つの小さいAI全部、どの判定でも効く（Gemma +0.10〜0.11、Qwen +0.06〜0.08、Phi +0.07〜0.08）。
- 珍しい語：言えない。Phi はやや悪くなる所あり。E19 の「珍しい語で効く」は、説明文に分類の語が出る組を外し語を入れ替えると繰り返せなかった。
- 旗2 SemEval：言えない。常識判定では Phi が少し悪くなる（−0.012〜−0.024）。
- 9B との比べ（W 全部）：3つとも SO が 9B より上（+0.07〜+0.09）、どの判定でも。SemEval では 9B と同着。
- 旗3（迷う所だけ鎖）：SO より少し下か同じで「足りない」。

## 見直しの後の確かめ（11-14 18時、ChatGPT・Gemini に README を見せた後）
- Gemini の指摘：よく出る段はしきい値を決めた同じ語で測っている（中・珍しい・SemEval は別の語）。
- よく出る語を半分に分け（種 0〜4）、半分でしきい値、残り半分の主な組で SO − S（5通りの正解すべて、analysis/e20/e20_holdout.py → results/E20/E20_holdout.json）。
- Gemma +0.08〜+0.12（25/25 効く）、Phi +0.04〜+0.09（25/25）、Qwen +0.03〜+0.09（23/25、2回同着）。伸びは少し小さくなる（特に Qwen）が、「よく出る語で効く」は残る。結果を見た後に足した確かめ。
