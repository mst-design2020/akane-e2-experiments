# E12 計画：辞書の説明文の頭の語の意味を、Gemmaにたくさん選ばせる（11-12、本人「やってみて」）

## 何を確かめるか
E8 の芯は「説明文の頭の語（dog → animal）の意味を Gemma 2B に選ばせる」こと。今までは約40問（Gemma 35/37、最初の意味 24/37）でしか測っていない。
人が意味を付けた公開の正解で、何万問も測って、本当に効くかを確かめる。

## 先行研究（E12_prior_work.md）
- 一番近い：Senseval-3 の WordNet 説明文の意味選び（Litkowski 2004）。全部の語が対象、一番 0.686、頭の語だけの成績・最初の意味の基準はなし、AIなし。
- Rigau 1998：辞書の頭の語の意味選び 61〜64%（手作りの方法）。
- Meconi 2025：文の中の意味選びで gemma-2-2b 72.4、最初の意味 65.2。
- 空き：頭の語だけ×学習なしの小さいAI×人が付けた正解で、最初の意味・Lesk・近さと比べる。新しさは小さい。

## データ
- Princeton WordNet 3.0 説明文コーパス（Gloss Corpus、noun.xml、github.com/sgjimenezv/wordnet_3_0_glosstag の写し。元の Princeton の置き場は2018年から切れている）。
- 名詞 82,115 の説明文から、頭の語＝spaCy で最初の名詞のかたまりの頭（E8n の取り方と同じ）。
- 使う問題：頭の語に人の印（tag="man"）が1つだけ付き、その語が1語の名詞で WordNet の意味が 2〜8 個。
  → 頭の語 34,402 問（頭の語の種類 4,035）。副に「〜の」の後ろの語（kind of X の X）7,855 問。
- 落とした物（数）：自動の印 10,793、印なし 15,683、2語以上のかたまり 12,325、意味が1つか9つ以上 7,182 ほか（e12_items.py の stats）。
- 正解が WordNet の最初の意味である割合：頭の語 60.5%、「〜の」後ろ 61.9%。

## 比べる方法
- S0 でたらめ（1/意味の数）
- S1 最初の意味（WordNet の順＝よく使う順。Wiktionary では同じ強さは期待できない）
- S2 Lesk（説明文と候補の説明文の重なり。重みは全説明文から数えたIDF。飛ばす語の一覧は使わない）
- S3 近さ（文ベクトル mpnet、E8 の方法C）
- **G Gemma 2B**（E8 の方法Dと同じ聞き方。候補はくじの順と逆順の2通りで聞いて平均。WordNet の順で聞くと最初の意味が先頭に来て漏れるため）
- 参考T WordNet の木（定義される語の上位にある候補を選ぶ。答えに近い情報を使うので比べ相手ではなく目安）
- 参考 Gemma を WordNet の順のまま 5,000 問（並べ順にどれだけ引っぱられるか）
- 同点はでたらめに割る（1/同点数）。

## 決まり（結果の前に固定）
- 主：頭の語 34,402 問の正しさ。G − S1、G − S2、G − S3。
- 「差あり」＝ 5ポイント以上、かつ頭の語ごとに引き直した95%幅（1000回）が0をまたがない（E11-1 と同じ基準）。
- 主の問い「Gemma は最初の意味より良いか」。良ければ E8 の意味選びは大量でも支えられる。並ぶか負けなら、E8 の 35/37 は小さい問題の偏りだった見込み（E8 は Wiktionary で最初の意味が使いにくい所に効いていた、と弱めて書く）。
- 副：正解が最初の意味でない 13,602 問での G と S2・S3、「〜の」後ろ、意味の数ごと、Gemma の自信ごとの正しさ（自信が高い時だけ使う手がかりになるか）、頭の語ごと平均。
- 2004年の参加者（0.686）は対象の語も版も違うので、並べて目安として書くだけ（勝ち負けは言わない）。

## 手で決めた所（ハードコードの点検）
- 数値：意味の数 2〜8、WordNet 順の参考 5,000問（くじ seed 0）、引き直し1000回、差の基準5ポイント。
- 文法：spaCy の名詞のかたまり、「of」の目的語（E8n と同じ。語の一覧ではなく文の形）。
- 語の形の正規表現 [a-z][a-z-]*。
- 手書きの語の一覧（飛ばす語・人の語など）はなし。e12_items.py・e12_local.py・e12_core.py を目で点検済み。

## 予想（先に書く）
Gemma 2B は 60〜75%。最初の意味（60.5%）とは差が出ない見込みが半分くらい。正解が最初の意味でない所では Lesk・近さより良い見込み。

## 限り
- WordNet の説明文と WordNet の意味で測る。E8 は Wiktionary なので、そのままは当てはまらない（意味の分け方が違う）。
- 人の印は1人ずつ付けた物で、間違いも含む。

## 結果（11-12 21:30、E12_analysis.json、ドライブ E12_results.json.gz id 1hV8U6fWhShaKHFEHz1w5eHhrU-U-769i）
主：頭の語 34,402問の正しさ
| 方法 | 正しさ | 頭の語ごと平均 |
|---|---|---|
| S0 でたらめ | 31.4% | 35.9% |
| S1 最初の意味 | 60.5% | 51.4% |
| S2 Lesk | 35.9% | 46.1% |
| S3 近さ | 67.9% | 66.5% |
| **G Gemma 2B** | **80.9%** | **76.9%** |
| 参考T WordNetの木 | 82.5% | 77.6% |

- G − S1 +20.5ポイント（95%幅 13.7〜28.2）、G − S3 +13.0（10.3〜16.3）、G − S2 +45.1 → 3つとも「差あり」。
- 正解が最初の意味でない 13,602問：Gemma 75.0%、近さ 65.9%、Lesk 34.8%。正解が最初の意味の所では Gemma 84.8%（最初の意味に15ポイント負け）。
- 「〜の」後ろ 7,855問：Gemma 73.9%、最初の意味 61.9%、近さ 60.8%（差あり）。
- 意味の数が増えると下がる（2つ 85.4% → 8つ 69.0%、最初の意味は 63.5% → 31.8%）。
- Gemmaの自信 0.9以上が82%の問題で、そこでの正しさ 86.5%。0.5〜0.7（13%）は 55.8%。
- WordNet の順のまま聞く参考（5,000問）：79.0%（並べ替え 81.3%）、1番目を選んだ割合 53.7%＝並べ順の癖は小さい。
- Gemma が自信高く外した 3,824問の多くは近い意味どうし（republic の「国」と「政治の形」、state の「領土」と「国の組織」など、writer・republic・state で1割）。
- 目安：Senseval-3（2004、全部の語、版も違う）の一番 68.6%。Rigau 1998 頭の語 61〜64%。
- 読み：決まりどおり「E8の意味選びは大量でも支えられる」。ただ E8 の 35/37（95%）は高すぎで、大量では約8割。
- 注意：WordNet の説明文はネットに多く、Gemma が覚えている見込みは消せない（Wiktionary の E8 とは別の所）。人の印にも間違いや近い意味の迷いがある。
