# E20 先行研究：辞書の鎖（TADORI）でしか届かない所はあるか（11-14）

## 近い研究
| 研究 | 何をしたか | E20 との違い |
|---|---|---|
| Chodorow ほか 1985（辞書から上下の階層を取り出す） | 辞書の説明文の頭の語（属）をたどって階層を作る | 古典。鎖をたどる部品そのもの。小さいAIで意味を選ばせる・知らない語で比べる、はない |
| Yin & Roth 2018「Term Definitions Help Hypernymy Detection」 | WordNet の説明文を語と一緒に学習モデルへ。BLESS AP .508（説明文なし .454） | 説明文 1 段を学習で使う。鎖はない。「説明文に上位語が書いていない組」は別に調べていない |
| Tikhomirov & Loukachevitch 2024（arXiv 2401.04515） | 小さい〜7B の言語モデルに文の確率で上位語を聞く。上へ1段ずつ上る「くり返し」で +0.02 MAP | 説明文を使わない。くり返しはAI自身の知識で上る（辞書でない） |
| TaxoLLaMA 2024（arXiv 2403.09207） | LLaMA-2 7B を WordNet で学習（説明文も入れる）。SemEval-2018 英語 MRR 54.4 | 学習が要る。珍しい語の分析なし。誤りの75%は「広すぎる」 |
| Mallen ほか 2023（PopQA） | 珍しい物ほど検索した資料が効く。珍しさで検索するか決める | 事実の問い。辞書の鎖・「一種か」ではない |
| NEO-BENCH 2024（arXiv 2402.12261） | 新語 2,505 語、翻訳・穴埋め・説明文作り・難しさ | 「一種か」の問いがない |
| SemEval-2018 Task 9（上位語を見つける） | 英語 1,500 語のテスト、人が作った上位語の正解、MAP | 公開の正解として使える（データの許諾は書いていない→リポジトリに入れない） |

## 空いている所
- 辞書の説明文を「1段見せる」研究と、「AI自身の知識で上る」研究はある。
- **辞書の説明文の鎖を小さいAIに意味を選ばせながらたどり、説明文に分類の語が書いていない所（1段では届かない所）で、1段見せる方法より良いか**を、珍しさ別・複数の小さいAIで測ったものは、調べた範囲では見当たらない。
- 「いつ鎖を使うか」（珍しさ・AIの自信で決める）を辞書の鎖でやったものも見当たらない。

## 落とし穴
- SemEval の上位語は WordNet と違う癖（広い語・言い換え）がある→NLI の最後の段が合わない時がある。
- Llama は HF で許可が要る。許可が無ければ Qwen・Gemma・Phi で。
- 正解が人のもの（SemEval）でも、「いいえ」の組は作る必要がある（他の語の上位語から選ぶ）。
